# 공개 사이트 — 볼트를 웹에 내보내는 규칙

볼트 `90_AI/` 의 노트를 Obsidian Digital Garden 플러그인으로 https://infiray-garden.vercel.app 에 공개한다. 보는 사람은 요청자와 지인이지만 주소는 전체 공개다(요청자 결정 2026-10-22, [[90_AI/지식저장소/원자료/대화/2026-10-22_대화_Digital-Garden-요청자-지시\|2026-10-22_대화_Digital-Garden-요청자-지시]]). 구성 경위는 [[90_AI/지식저장소/원자료/산출물/2026-10-22_산출물_Digital-Garden-공개-구성\|2026-10-22_산출물_Digital-Garden-공개-구성]].

## 공개 범위

플러그인은 `dg-publish: true` 가 붙은 노트만 올린다. 어느 노트에 붙이는지는 규칙으로 정하고 스크립트가 붙인다.

| 구분 | 대상 |
|---|---|
| 제외 | `원자료/` 전체(대화 · 검토 · 산출물 · 조사) |
| 제외 | 운영 파일: CLAUDE.md · README.md · index.md · log.md · `*-log.md` · 이어하기.md · 할일.md · `*-할일.md` · `할일/` · `헷갈리는점/` · `기억/` · `아카이브/` |
| 제외 | `도구/`(템플릿 · 스킬 · 설치 · 스크립트) |
| 제외 | `*.excalidraw.md` 원본. 노트에 임베드된 그림은 발행 때 SVG 로 바뀌어 보인다 |
| 제외 | 캔버스 `.canvas`(플러그인은 지원하지만 이번에는 보류) |
| 공개 | 그 외 전부. 2026-10-22 기준 100개(claude 11 · 지식저장소 위키 4 · dbdzzk 9 · momo-english-academy 22 · pickzzk 55, 이 쪽 포함) |

공개되면 안 되는 내용은 `원자료/` 에 둔다. 비밀값 · 토큰 · 개인 연락처는 어느 노트에도 적지 않는다.

## 표시 스크립트

규칙 정본은 `지식저장소/도구/dg-mark.py` 다.

| 명령 | 하는 일 |
|---|---|
| `python3 90_AI/지식저장소/도구/dg-mark.py` | 바뀔 노트만 보여 준다(미리보기) |
| `python3 90_AI/지식저장소/도구/dg-mark.py --apply` | 포함 노트에 `dg-publish: true` 를 붙이고, 제외 노트에 붙어 있으면 뗀다. 프런트매터가 없는 노트에는 블록을 새로 만든다 |

몇 번 돌려도 결과가 같다. 파일 이름은 NFC 로 맞춘 뒤 비교하므로 iCloud 가 만든 NFD 이름도 같은 규칙에 걸린다. 노트를 만들거나 옮긴 뒤, 그리고 발행 직전에 돌린다.

## 발행 절차

| 차례 | 누가 | 하는 일 |
|---|---|---|
| 1 | Claude | `dg-mark.py --apply` 로 표시를 맞춘다 |
| 2 | 요청자 | Obsidian 명령 팔레트에서 "Digital Garden: Publish Multiple Notes" 를 실행한다. 바뀐 노트만 저장소에 올라가고 Vercel 이 다시 짓는다 |
| 3 | Claude | 사이트에서 새 쪽 · 그림 · 링크를 확인한다 |

공개하지 않은 노트로 가는 링크는 사이트에서 "없는 노트" 로 보인다. 원자료를 많이 가리키는 INDEX 류 쪽에서 그런 링크가 보이는 것은 의도한 결과다.

## 플러그인 설정값

`data.json` 과 저장소 `.env` 에 같은 값을 두었다. 설정 화면에서 바꾸면 플러그인이 `.env` 를 다시 커밋한다.

| 설정 | 값 | 이유 |
|---|---|---|
| slugify | 끔 | 켜면 `@sindresorhus/slugify` 가 한글을 지워 주소가 비거나 겹친다 |
| 경로 재작성 | `90_AI/:` | 주소에서 `90_AI/` 접두어를 뗀다 |
| 갱신일 | 프런트매터 `updated`, 꼴 `yyyy-MM-dd` | 볼트 규칙의 `updated` 속성을 그대로 보여 준다 |
| 노트 표시 | 파일 트리 · 검색 · 백링크 · 로컬 그래프 · 인라인 제목 · 목차 · 링크 미리보기 · 태그 켬 | 폴더 구조로 돌아다닐 수 있게 |
| 사이트 이름 · 언어 | infiray garden · ko | |
| 홈 질문 | 끔(`dontAskAboutHomePage`) | 발행마다 홈으로 할지 묻지 않게 |

## 주의

| 항목 | 내용 |
|---|---|
| 토큰 | GitHub fine-grained 토큰은 저장소 `infiray-garden` 하나에만, Contents · Pull requests 읽기 · 쓰기. 요청자가 Obsidian 설정에 직접 붙이고 채팅으로 주고받지 않는다 |
| 평문 저장 | 토큰은 `data.json` 에 평문으로 남는다. LiveSync 가 플러그인 폴더까지 동기화하면 다른 기기와 서버로 퍼진다. 그 파일을 다른 곳에 옮기지 않는다 |
| 전체 공개 | 접근 제한(비밀번호 보호)은 Vercel 유료 요금제 기능이다. 공개가 곤란한 내용은 처음부터 원자료에 둔다 |
