## 공개 범위

플러그인은 `dg-publish: true` 가 붙은 노트만 올린다. 어느 노트에 붙이는지는 규칙으로 정하고 스크립트가 붙인다.

| 구분 | 대상 |
|---|---|
| 제외 | `원자료/` 전체(대화 · 검토 · 산출물 · 조사) |
| 제외 | 운영 파일: CLAUDE.md · README.md · index.md · log.md · `*-log.md` · 이어하기.md · 할일.md · `*-할일.md` · `할일/` · `헷갈리는점/` · `기억/` · `아카이브/` |
| 제외 | `도구/`(템플릿 · 스킬 · 설치 · 스크립트) |
| 제외 | `*.excalidraw.md` 원본. 노트에 임베드된 그림은 발행 때 SVG 로 바뀌어 보인다 |
| 제외 | 캔버스 `.canvas`(플러그인은 지원하지만 이번에는 보류) |
| 공개 | 그 외 전부. 2026-10-22 기준 100개(claude 11 · 지식저장소 위키 4 · dbdzzk 9 · momo-english-academy 22 · pickzzk 55, 이 쪽 포함) |

공개되면 안 되는 내용은 `원자료/` 에 둔다. 비밀값 · 토큰 · 개인 연락처는 어느 노트에도 적지 않는다.

## 표시 스크립트

규칙 정본은 `지식저장소/도구/dg-mark.py` 다.

| 명령 | 하는 일 |
|---|---|
| `python3 "<볼트>/90_AI/지식저장소/도구/dg-mark.py"` | 바뀔 노트만 보여 준다(미리보기). 기본 루트가 절대 경로여서 어느 디렉터리에서 불러도 된다 |
| `python3 "<볼트>/90_AI/지식저장소/도구/dg-mark.py" --apply` | 포함 노트에 `dg-publish: true` 를 붙이고, 제외 노트에 붙어 있으면 뗀다. 프런트매터가 없는 노트에는 블록을 새로 만든다 |

몇 번 돌려도 결과가 같다. 파일 이름은 NFC 로 맞춘 뒤 비교하므로 iCloud 가 만든 NFD 이름도 같은 규칙에 걸린다. 노트를 만들거나 옮긴 뒤, 그리고 발행 직전에 돌린다.

2026-10-23 부터는 손으로 돌릴 일이 거의 없다(요청자 지시 [[90_AI/지식저장소/원자료/대화/2026-10-23_대화_Digital-Garden-표시-자동화-지시\|2026-10-23_대화_Digital-Garden-표시-자동화-지시]]). 사용자 수준 Stop 훅 `~/.claude/hooks/dg_mark_hook.py`(`~/.claude/settings.json` 의 Stop 목록)가 Claude Code 의 모든 세션에서 턴이 끝날 때마다 `--apply` 를 돌리고, 표시가 바뀐 노트가 있을 때만 "공개 표시 자동 적용: 표시 N (파일)" 알림을 띄운다. 바뀜이 없으면 조용하고, 볼트가 없거나 스크립트가 실패해도 턴을 막지 않는다. 손으로 미리보기를 보고 싶을 때는 Claude Code 에서 `/dg-mark` 스킬을 부른다(요청자가 2026-10-23 설치, 원본 사본은 `도구/dg-mark-SKILL.txt`).

## 발행 절차

| 차례 | 누가 | 하는 일 |
|---|---|---|
| 1 | 훅(자동) | 턴이 끝날 때 Stop 훅이 `dg-mark.py --apply` 를 돌려 표시를 맞춘다. 표시된 노트의 내용만 바뀐 때는 이 단계에 걸리지 않고 2 로 바로 간다 |
| 2 | 요청자 | Obsidian 명령 팔레트에서 "Digital Garden: Publish All Notes Marked for Publish" 를 실행한다(2.102.0 이름. Publication Center 에서도 된다). 바뀐 노트만 저장소에 올라가고 Vercel 이 다시 짓는다 |
| 3 | Claude | 사이트에서 새 쪽 · 그림 · 링크를 확인한다 |

공개하지 않은 노트로 가는 링크는 사이트에서 "없는 노트" 로 보인다. 원자료를 많이 가리키는 INDEX 류 쪽에서 그런 링크가 보이는 것은 의도한 결과다.

## 플러그인 설정값

`data.json` 과 저장소 `.env` 에 같은 값을 두었다. 설정 화면에서 바꾸면 플러그인이 `.env` 를 다시 커밋한다.

| 설정 | 값 | 이유 |
|---|---|---|
| slugify | 끔 | 켜면 `@sindresorhus/slugify` 가 한글을 지워 주소가 비거나 겹친다 |
| 경로 재작성 | `90_AI/:` | 주소에서 `90_AI/` 접두어를 뗀다 |
| 갱신일 | 프런트매터 `updated`, 꼴 `yyyy-MM-dd` | 볼트 규칙의 `updated` 속성을 그대로 보여 준다 |
| 노트 표시 | 파일 트리 · 검색 · 백링크 · 로컬 그래프 · 인라인 제목 · 목차 · 링크 미리보기 · 태그 켬 | 폴더 구조로 돌아다닐 수 있게 |
| 사이트 이름 · 언어 | infiray garden · ko | |
| 홈 질문 | 끔(`dontAskAboutHomePage`) | 발행마다 홈으로 할지 묻지 않게 |

## 주의

| 항목 | 내용 |
|---|---|
| 토큰 | GitHub fine-grained 토큰은 저장소 `infiray-garden` 하나에만(Only select repositories), Contents · Pull requests 읽기 · 쓰기. 요청자가 Obsidian 설정에 직접 붙이고 채팅으로 주고받지 않는다. 쓰기 권한이 없으면 발행이 `Resource not accessible by personal access token` 으로 조용히 실패한다. 권한 확인은 `GET /repos` 의 `permissions.push` 가 아니라 블롭 생성 같은 쓰기 호출로 한다 |
| 평문 저장 | 토큰은 `data.json` 에 평문으로 남는다. LiveSync 가 플러그인 폴더까지 동기화하면 다른 기기와 서버로 퍼진다. 그 파일을 다른 곳에 옮기지 않는다 |
| 전체 공개 | 접근 제한(비밀번호 보호)은 Vercel 유료 요금제 기능이다. 공개가 곤란한 내용은 처음부터 원자료에 둔다 |

## 템플릿 수정

템플릿은 창 너비 1400px 미만에서 오른쪽 칸(그래프 · 목차 · 백링크)을 접힌 아래 패널로 바꾼다. 아이패드 프로는 CSS 픽셀이 13형 가로 1366 · 11형 가로 1194 라 항상 접혔다(요청자 지시 2026-10-22 "옵시디언처럼 오른쪽에 개요랑 그래프뷰가 같이 보이는 형태"). 그래서 가든 저장소의 템플릿을 고쳤다.

| 파일 | 수정 |
|---|---|
| `src/site/styles/digital-garden-base.scss` · `src/site/_includes/components/sidebar.njk` · `src/site/_includes/components/graphScript.njk` | 접힘 기준 1400px → 1100px |
| `src/site/styles/custom-style.scss`(사용자 파일) | 1251~1400px: 파일 트리 220 · 본문 600 · 옆 칸 280 · 그래프 240. 1101~1250px: 200 · 560 · 260 · 220 |

세로로 든 아이패드(1024 · 834)는 그대로 접힌다. 플러그인이 템플릿 갱신 PR 을 보내면 앞의 세 파일이 바뀌었는지 보고 1100px 치환을 다시 한다. 사이트 확인 폴링은 30초 이상 간격으로 한다(10초 간격 curl 에 Vercel 봇 차단이 걸렸다).
