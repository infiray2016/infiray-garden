| | parent_auth | 부모 PIN 해시, 연속 실패 수, 잠금 해제 시각. 접근 코드 실패의 IP 행도 이 테이블의 종류 access_ip 행(IP 해시 · 실패 수 · 잠금 해제 시각 · 갱신 시각)이다(C56, [[90_AI/프로젝트/momo-english-academy/원자료/검토/2026-10-16_검토_P3-하위-plan-계획자-보고\|2026-10-16_검토_P3-하위-plan-계획자-보고]]) |

| 학습 기록 | sessions | 세션 1회. lesson_id, 종류, 쓰기 6단계 이상의 세션 차례, 회화의 지금 토막, 상태, 점수, 영어로 말한 문장 수 |
| | attempts | 활동별 시도. 기기가 만든 시도 id, 입력, 시도 시각(C45), AI 피드백, 점수, 단어별 정오, 단어 수, 상태(완료 · 첨삭 대기 · 첨삭 못 함). 회화의 오늘 쓸 말 · 말해 보기 · 정리에서 따라 말한 시도도 여기 둔다 |
| | talk_turns | 회화 턴. 턴 번호, 토막(인사 · 대화 · 더 이야기하기 · 정리), 화자, {NAME} 바꾸기와 가림 뒤 원문, 입력 방식, 힌트 종류 · 쓴 힌트 단 · 들은 도움, 노린 단원 단어와 처음 묻는 턴 · 다시 묻는 턴 구분, 스스로 쓴 단원 단어, 막힘으로 볼 말(C36), 카드 질문 번호(C19), '말했다' 단어, 보낸 메시지 전문, 다시 쓸 토리 차례, 체감 대기 · 듣기 끝 대기 · 확인을 건너뛰었는지(C23) |
| | talk_summaries | 지난 대화 요약. 한국어, talk.summary_max_chars(300자) 이하 |

| | unit_progress | 프로필 × 영역 × 단계 × 단원 × 회차. 시작 개정, 설정 판, 판정 설정값 복사본, 보강 횟수, 부모 확인 |
| | level_tests | 단계 · 배치 · 재배치 평가. 벌, 시작 개정, 설정값 복사본, 문항 점수, 통과 여부 |
| | star_ledger | 별 원장. 학습일, 영역, 세션, 이유, 개수 |
| | badges | 받은 배지. 영역 · 단계 · 단원과 받은 시각. 배지는 2차 기능이다 |
| | daily_sentences | 오늘의 한 문장. 학습일, 영역, 문장, 출처 attempt. 2차 기능이다 |
| 운영 · 기록 | ai_calls | AI 호출 기록. 본문은 저장하지 않는다 |
| | ai_status | 'AI 쉬는 중' 상태. 집 전체에 한 행이다. 쉬는 중 여부, 까닭(하루 안전 상한 · 콘솔 한도 · 연결 장애 · 계정 확인 필요), 시작 시각, 풀리는 시각, 다음 확인 시각, 확인 차례, 확인 모델, 이어진 실패 수. 하루 안전 상한은 풀리는 시각과 다음 확인 시각이 둘 다 다음 학습일 시작이고, 연결 장애 · 계정 확인 필요는 풀리는 시각 칸을 비운다(C46) |
| | progress_events | 자동 판정 · 부모 조정 · 되돌림 · 평가 미통과 진급 · 다음 단계 준비 중 · 시드 정정에 따른 다시 계산 · 다시 계산으로 거둘 일이 생김. 종류, 대상, 이전 값 · 새 값, 주체, 시각 |
| | parent_alerts | 부모 알림. 종류, 기준 키, 값, 학습일, 확인 시각 |
| | seed_reports | 시드 문제 신고. 신고자, 사유, 상태(접수 · 확인 · 문제 없음 · 정정 적재), 정정 판 |

복습 카드가 속하는 영역(하루 15장을 세는 영역)은 그 상태로 숙달을 세는 영역 가운데 아이가 처음 만난 영역이다. vocab_progress 의 처음 만난 영역 · 만난 영역 목록이 이것을 정한다(3.4 · C47). 쓰기 단원 단어와 겹치는 두 단계 카드는 철자 타일 단계의 정오를 '씀' 행에, 뜻 고르기 단계의 정오를 '알아봄' 행에 남긴다(C24 · C45). 말하기 단원 단어 카드의 철자 연습 결과는 남기지 않는다(C8). '말함' 행은 그 단어를 회화에서 처음 만날 때 만든다. 오늘 쓸 말 · 말해 보기에 나온 때와 토리 말에서 단원 단어를 찾은 때가 만남이다. 대화를 지워도 이 행은 남는다(B5-15).

## 시드 판과 적재

| 항목 | 규칙 |
|---|---|
| 칸 | 수업은 (영역, 단계, 단원, 종류, 수업 번호, 주제 변형)이다. 단계 평가 문항은 (영역, 단계, 벌, 문항 번호), 배치 평가 문항은 (영역, 단계, 벌, 문항 번호, 예비 여부), 회화 평가 카드는 (영역, 단계, 벌, 장 번호)다. 회화 평가 카드의 턴은 행의 내용 JSON 에 차례대로 둔다. level_tests 의 문항 점수와 seed_reports 의 문항 번호는 회화 평가에서 (장, 턴)으로 적고, 다시 계산에서 한 문항은 한 턴이다(B5-16) |
| 판 | '개정.정정' 두 자리다(예 3.0 · 3.1). 개정 자리는 시드 전체에서 하나로, 정정 자리는 행마다 센다 |
| 개정 · 정정 | 개정 판은 분량 · 새 단어 · 규격 · 프롬프트가 바뀐 판이고 다음 단원부터 쓴다. 정정 판은 문제와 정답 표시만 고친 판이고 진행 중 단원에 바로 쓴다(R5) |
| 고르기 | 칸마다 단원 시작 개정(unit_progress) 이하에서 가장 높은 판을 읽는다. 평가는 level_tests 의 시작 개정을 쓴다 |
| 보존 | 이전 판 행은 지우지 않는다. 바뀌지 않은 칸은 새 행을 만들지 않는다. 판마다 바뀐 칸과 이유는 seed/manifest 에 남긴다 |
| 적재 | `pnpm seed:load` 가 검증을 다시 돌리고 한 트랜잭션으로 새 행만 넣는다. 실패 칸이 하나면 한 행도 넣지 않는다. 두 번 돌려도 결과가 같다 |
| 마이그레이션 | 열 · 테이블을 더하기만 한다. 열을 지우는 것은 그 열을 읽지 않는 코드가 승격된 다음 배포에서 한다 |
| 설정값 시드 | '시드' · '결정 기록 먼저' 키는 시드 값으로 고치고 settings_history 에 남긴다. '고급' · '기본' 키는 행이 없을 때만 넣는다. 바꾸는 값도 6.1 조합 검사와 3.2 관계 표를 통과해야 하고, 못 하면 적재 전체가 실패한다. 범위가 '프로필'인 키는 profile_id 를 비운 기본 행을 넣는다. 읽을 때는 그 프로필의 행을, 없으면 기본 행을 쓴다(12절, B5-19) |

수업 시드는 `seed/lessons/<영역>/<단계>/<단원>.json` 으로 나눈다. 수업 하나와 시드 전체의 크기는 표본 생성 때 잰다. 만드는 절차는 [[90_AI/프로젝트/momo-english-academy/위키/제품/파이프라인/수업-생성\|수업-생성]]에 있다.

## 세션 상태 전이

상태는 진행 · 완료 · 보관 · 중단 넷이다. 세션은 아이가 시드 수업을 시작할 때 만든다. 미리 만들어 두는 '준비' 상태는 없다.

| 전이 | 계기 |
|---|---|
| 진행 → 완료 | 수업을 끝낸다. 회화는 목표 턴에 닿을 때다. 그 뒤 '더 이야기하기' 턴은 같은 세션에 '목표 턴 밖'으로 붙는다 |
| 진행 → 보관 → 진행 | 부모가 단계 · 단원을 옮기면 보관한다. 그 단원에 다시 들어가면 이어 한다 |
| 진행 → 중단 | 다른 수업을 고른다(확인 뒤). 회화 목표 턴 전에 '그만하기'를 누른다(확인 뒤). session.resume_hours(24시간)가 지난다 |
| 진행 → 지움 | 첫 활동에서 '홈'을 누르면 기록 없이 지운다 |

프로필 × 영역마다 진행 중 세션은 하나다(부분 유일 색인). 중단은 단원 횟수 · 최근 성적 · 별에 넣지 않는다. 단어별 정오와 회화의 '말했다'만 남긴다. 회화 목표 턴 전 '홈'은 진행으로 남는다(C34). 배치 평가는 시간이 지나도 닫지 않는다.

## 순수 함수

DB 에 의존하지 않는 순수 함수로 나누고 Vitest 로 경계값까지 본다(9절). 날짜 판정은 현재 시각을 인자로 받는다.

| 묶음 | 함수 |
|---|---|
| 진도 판정 | 단원 통과 판정(구간별 틀, 최소 수업 수 · 최소 학습일 수, 회화의 '말함' 비율), 단계 승급 판정(문항 점수 합, 다음 단계 준비 중), 배치 평가 시작 단계 |
| 수업 고르기 | 어휘 배정, 수업 목록 상태('여기부터 해요' 순서, 잠긴 단원의 남은 조건 포함), 보강 · 연습 수업 고르기, 주제 변형 고르기, 시드 판 고르기 |
| 복습 · 보상 | 간격 반복 스케줄과 복습 카드 순서, 복습 카드 꼴과 속하는 영역 고르기(C47), 점수 계산, 별 계산, 친한 정도, 연속 일수, 학습일, 오늘 완료 · 이번 주 n일 |
| 회화 | 문장 단위 검사, 힌트 종류 기록과 '말했다' · '안다' 계산, 처음 묻는 턴 · 다시 묻는 턴 판정과 '모름' 턴 세기, 평가의 허용 답 판정과 힌트 단 점수, 정리 토막의 되짚을 말 고르기 |
| 말 · 응답 | 따라 말하기 일치율, 영어로 말한 문장 수, 말소리 없음 세기, 실시간 응답 정규화 |
| AI · 운영 | 비용 알림 · 안전 상한 판정, 'AI 쉬는 중' 들어가기 · 풀기와 확인 호출 모델 고르기, 모델 · effort · 생각 단계 조합 검사, DB 크기 알림 판정 |
| 시드 | 시드 검증(검증 스크립트와 CI 가 같은 함수를 쓴다), 신고 뒤 다시 계산(한쪽으로만), 설정값 시드 적재의 값 견주기 |

세션을 여는 서버 액션은 고른 수업이 열린 수업인지 서버에서 다시 판정한다. 신고 서버 액션은 받은 id 가 그 프로필의 그 세션에서 낸 것인지 확인한다.
