# 사다리와 승급

영역마다 12단계 사다리가 따로 있고, 단계 안에 단원 5개가 있으며, 승급은 수업 횟수가 아니라 숙달로 판정한다(요청자 결정 2026-10-15). 정본은 spec 3절이다. 1회차 검토(2026-10-15)로 바뀌기로 한 것은 "잠정"으로 표시했고, 회화 영역은 제안 단계라 spec 에 없다.

## 영역과 단계

| 영역 | 포스트잇 색 | 상태 |
|---|---|---|
| 읽기 | 노랑 | spec |
| 쓰기 | 하늘 | spec |
| 말하기 | 분홍 | spec. 회화가 들어오면 역할극을 회화로 옮기고 따라 말하기 · 질문 답 · 듣기에 집중(제안) |
| 회화 | 초록 | 제안([[90_AI/프로젝트/momo-english-academy/원자료/산출물/2026-10-15_산출물_회화-영역-제안\|2026-10-15_산출물_회화-영역-제안]]), AI 친구 토리 |

| 단계 | CEFR | 학교 수준(참고값, 학년과 묶지 않음 — 잠정 A4) |
|---|---|---|
| 1~3 | Pre-A1 | 초4~5 |
| 4~6 | A1 | 초6~중1 |
| 7~9 | A2 | 중2~3 |
| 10~12 | B1 | 중3~고1 |

어휘 뼈대는 교육과정 기본 어휘인데 수치는 두 번 바뀌었다. spec v1 의 "중학교까지 1,800"은 오류였고(A-06, 2015 개정은 초등 500 · 중 1,250 · 고1 1,800), 편집자가 2022 개정 원문을 확인해 학습 어휘 누계 초등 600 · 중학교 1,500 · 공통영어 1,800 으로 적었다. 단원 어휘가 30개 고정이라 앱 누계는 3단계 450 · 6단계 900 · 9단계 1,350 · 12단계 1,800 이고 교육과정과의 차이는 spec 3.4 에 적혀 있다. 12단계(B1)까지 유지하고 intent 목표를 "중학교(A2)를 지나 B1 까지"로 고쳤다(잠정 A12).

## 단원과 승급 판정

| 판정 | spec v1 | 1회차 뒤(잠정) |
|---|---|---|
| 어휘 "안다" | 서로 다른 날 복습 3회 연속 정답. 복습 화면은 "알아요 · 몰라요" 자기 평가 | 앱이 채점한다(뜻 고르기 4지선다, 쓰기 · 말하기 단어는 철자 타일). 단어마다 '알아봄' · '씀' 두 상태. 자기 평가는 숙달에 쓰지 않음(A-02, A2) |
| 단원 통과 | 어휘 80% "안다" + 최근 5회 과제 평균 80%, 최소 수업 6회 | 같음. 최소 수업은 8회(쓰기 6단계 이상 5회), 단원당 준비 수업은 13회(배정 8 + 다지기 5). 복습 간격은 1 · 2 · 4일, 안 뒤 30일. 점수 규격(0~100, 영역별 뜻)을 3.7 로 신설(B1-08). 점수 없는 세션은 평균에서 빼고 횟수에 넣음(D11) |
| 못 미칠 때 | 보강 수업을 계속 생성 | 보강 4회 뒤 부모 확인 표시, 부모가 다음 단원 · 한 번 더 · 단계 내리기 선택, 3일 안에 고르지 않으면 다음 단원(A-03, A3) |
| 단계 승급 | 단원 5개 통과 뒤 단계 평가 20문항 80% | 같음. 자동 하향 없음, 올리기 · 내리기 추천만 표시(D9) |
| 시작 단계 | 배치 평가(고정 문항) | 1차는 첫 실행 화면에서 부모가 영역별 시작 단계(기본 1)와 관심 주제를 고르고 '알파벳을 아직 몰라요'를 고를 수 있음. 배치 평가는 2차에 적응형(3단계에서 시작, 단계마다 3문항, 최대 15문항, 3개 다 맞히면 두 단계 오르기, 한 단계 낮게 시작)(D10 · A-18) |
| 재평가 | 없음 | 3개월마다 재배치 평가(평행 문항 2벌)를 2차에 넣고 성공 기준에 씀(A11) |

## 영역별 사다리 요약

사다리 표는 1회차 A-05 로 단계마다 한 행(1~12)으로 펼친다(이웃 단계는 분량이나 과제가 반드시 달라진다). 아래는 뼈대만이다.

| 영역 | 1~3 (Pre-A1) | 4~6 (A1) | 7~9 (A2) | 10~12 (B1) |
|---|---|---|---|---|
| 읽기 | 1단계 그림과 짝지은 단어 · 문장 1~3개, 2단계 3~5문장(1~2단계는 문제 5개), 3단계부터 50단어 안팎. 4단계 글 종류는 '그림 설명' 대신 '짧은 안내문' | 90~140단어 일상 이야기, 사실 확인 + 추론 | 150~200단어 편지 · 설명문 | 200~300단어 기사 · 에세이, 주제 · 추론 · 문맥 추측 |
| 쓰기 | 고르기 · 베끼기 · 글자 채우기 · 받아쓰기 · 카드 조립. AI 없음 | 4~5 문장 틀 · 단어 바꾸기 + 가벼운 확인(고칠 곳 1). 6 자유 작문 4~5문장 + 첨삭 | 한 문단 6~8문장, 과거 · 미래, 접속사 | 100~150단어 의견 · 비교 · 설명 |
| 말하기 | 따라 읽기, 한 문장 답 | 역할극(5단계부터, 회화로 옮길 수 있음), 3~4문장 답 | 역할극, 후속 질문 | 주제 발표 1~2분, 의견 |
| 회화(제안) | 보기 고르기 · 빈칸 틀, recast 만 | 4 힌트 3단, 5~ 상황극 미션 | 주제 대화, 후속 질문 2 | 자유 대화 3분, 도움 없음 |

쓰기 6단계 이상은 타자 시간만으로 5~8분을 넘으므로 한 과제를 두 세션(초고 · 첨삭과 고쳐 쓰기)으로 나눈다(A-12, A5). 그래도 10~12단계 초고는 목표 10분이라 기본 세션 길이를 넘는 우려가 남아 사용 시험에서 재기로 했다. 말하기 단계마다 듣기 이해 활동 1~2문항을 넣는다(A6). 쓰기 · 말하기 사다리의 단계별 문장 수 · 단어 수 · 턴 수 · 발표 시간과 세 영역의 단계별 목표 시간, 3.6절 학습 요소 60개씩의 순서는 편집자가 정한 기준안이라 요청자 확인이 필요하다.

## 피드백 한도

| 영역 · 단계 | 피드백 |
|---|---|
| 쓰기 1~3 | 정답 비교. 틀리면 정답을 보여 주고 다시 |
| 쓰기 4~5 | 칭찬 한 줄 + 고칠 곳 최대 1개, 모범 답안 없음 |
| 쓰기 6~12 | 생각 꺼내기(한국어 질문 2~3개, 답은 보기 3개 누르기 또는 한글 입력) → 쓰기 → 첨삭(칭찬 1 · 교정 최대 2, 10~12단계는 3 · 루브릭) → 고쳐 쓰기 1회 → 내 문장 말하기. 모범 답안은 고쳐 쓰기 뒤에(A-09). 아이 화면에는 점수 없이 칭찬과 교정만 보인다 |
| 말하기 | 일치율은 앱이 계산(정규화 규칙 B1-16), 내용 피드백 · 문법 지적 최대 1. 점수는 일치율 비중 0.5, 듣기 비중 0.2(편집자 기본값) |
| 회화 1~4(제안) | recast 만, 틀렸다고 하지 않음 |
| 회화 5~12(제안) | 끝난 뒤 "잘한 말 2 · 다음엔 이렇게 1" |

## 동기 요소 (잠정)

| 요소 | 내용 | 출처 |
|---|---|---|
| 별 | 누적형. 세션 완주 1 + 재도전 1 + 그날 복습 1, 영역마다 하루 첫 세션만. 아바타 꾸미기는 3차 | A8 |
| 연속 일수 | 영역별이 아니라 하나(그날 한 영역 이상), 주 2일 쉬는 날 허용, 카드에 '이번 주 n일' | A7 |
| 하루 세션 | 영역당 새 수업 1회, "한 번 더"는 허용하되 별 없음 | D8 |
| 오늘의 한 문장 | 그날 만든 문장 하나를 홈에 붙임(리얼 아카데미 1일 1아웃풋) | 조사 |
| 실물 보상 | 부모가 등록, 홈에 목표로 표시 | 조사 |
| 친한 정도 | 토리와 10칸, 다 차면 새 주제(제안) | 회화 제안 |
