# UI · UX 개선 — 요청자 "디자인이 너무 허접하고 실제 학습을 할 때 불편한 점이 많았어"

2026-10-29 17:0x 요청자 지시로 연 변경 단위. 첫 걸음은 설계 검토자의 경험 검토 [[90_AI/프로젝트/momo-english-academy/원자료/검토/2026-10-29_검토_프리뷰-사용자-경험\|2026-10-29_검토_프리뷰-사용자-경험]](읽기용 쪽 https://claude.ai/artifact/DfMFX8rBKYW7K7kmAwc4g6). 근거는 CI 25차 e2e 사진 243장 · 코드 · 정본 4절 · 7절 · 10-26 기록.

## 요지

"별로였다"의 상위 원인 셋: (1) 내가 한 일에 되돌아오는 것이 없다(듣는 중 표시는 고리뿐 · 보내면 화면이 비고 점 셋 · 바로 보내는 턴은 아이 말이 안 보임) (2) 실패가 조용히 지나가거나 '홈'뿐인 막다른 길로 끝난다(세 번 실패 말없는 건너뜀 · 빈 듣기 두 번의 조용한 '모름' · 읽어 주기 사건이 안 오면 대화 턴이 안 열림) (3) 보상도 쌓임도 없다(별 없음 P12 · 홈 첫 상태 0 투성이 · 칭찬 1~2초). Critical 2(U5-2 오늘 쓸 말 인식 실패 연쇄 — 10-26 재현 경로, U5-1 읽어 주기 감시 타이머 없음 + 대화 턴이 읽기 끝까지 말하기 단추를 안 그림 — 7절 C53 (2) 어긋남). 요청자 결정 R1~R8(대화 턴 읽는 동안 단추 · 따라 말하기 단추 · 별 · 단어 당길지 · 설정값 둘 · 말하기 영역 선생님 · 막힘 화면 '다시 해 볼래요' · 홈 첫 사용 꼴 · 기다리는 동안 앱 맞장구). 묶음 제안: 회화 재설계에 넣을 것 / 별도 UI · UX 변경 단위 / 결함 바로 고침 / 정본 변경 행.

## 디자인 완성도(2판 덧붙임)

'허접' 첫인상은 D-1 화면 반이 빈 코르크 · D-2 앱의 얼굴(마스코트) 없음 · D-3 질감 없는 평면이 만든다. 정본의 디자인 결정(포스트잇 네 색 · 글꼴 셋)은 두고 손질할 것과, 시안을 번호로 골라야 할 것(R9 바탕 은유 · R10 앱의 얼굴 · R11 선생님 창 틀 · R13 색 세트)을 갈랐다. 시안은 '홈 · 회화 대화 · 결과' 세 화면을 같은 번호로 묶어 3~5개 — 브리프 `task-design-samples.md` → 검토 7.6 대로 시안 다섯(코르크 깊이 · 밝은 책상 · 교실 칠판 · 그림책 · 지금 + 손질, 색 세트는 각 시안 안 견본 띠)으로 맞춤. 7절 판정 Critical 2(D-1 · D-2) · Important 5(D-3~D-7).
