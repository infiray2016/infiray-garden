# 모모 잉글리시 아카데미 사용 설명서

구현 전 초안이다. 검토 1회차 반영본 spec(2026-10-15) 기준으로 썼고, 구현 차수가 끝날 때마다 실제 화면에 맞춰 고친다. 회화 영역은 제안 단계라 넣지 않았다.

## 처음 시작하기 (부모)

| 순서 | 하는 일 |
|---|---|
| 1 | 집 태블릿이나 PC 의 Chrome · Edge · Safari(iPad 는 iPadOS 17 이상 Safari)로 앱 주소를 연다 |
| 2 | 가족 접근 코드를 넣는다. 한 번 넣으면 그 기기에서 1년 동안 다시 묻지 않는다. 코드를 바꾸면 모든 기기에서 다시 넣어야 한다 |
| 3 | 부모 PIN 을 정한다. 5회 틀리면 15분 잠긴다 |
| 4 | 아이 프로필을 만든다(이름 · 아바타 · 관심 주제) |
| 5 | 첫 실행 화면에서 영역(읽기 · 쓰기 · 말하기)마다 시작 단계를 고른다. 기본은 1단계이고 '알파벳을 아직 몰라요'를 고를 수 있다. 2차부터는 배치 평가가 대신 정한다 |
| 6 | 첫 수업 두 개가 바로 만들어지고 나머지는 뒤에서 준비된다. 수업이 준비되는 데 보통 1시간, 길면 하루가 걸린다 |

## 매일 하기 (아이)

| 화면 | 하는 일 |
|---|---|
| 홈 | 포스트잇 세 장(읽기 노랑 · 쓰기 하늘 · 말하기 분홍)에서 하나를 누른다. 단계, 단원 진행 5칸, 아는 단어 수, 이번 주 학습 일수가 보인다. 영역마다 하루 새 수업 1회이고 '한 번 더'는 횟수 제한 없이 할 수 있다 |
| 읽기 세션 | 새 단어 보기 → 지문 읽기(읽어 주기 버튼, 단어를 누르면 뜻) → 문제 풀기 → 틀린 문제 해설. 5~8분 |
| 쓰기 세션 | 1~3단계는 그림 보고 단어 고르기 · 베껴 쓰기 · 글자 채우기 · 받아쓰기 · 단어 카드 순서대로 놓기. 4~5단계는 문장 틀에 단어 넣기와 바로 확인(고칠 곳 하나). 6단계부터는 생각 꺼내기(한국어 질문에 보기 고르기) → 초고 쓰기, 다음 세션에 선생님 답장 보고 고쳐 쓰기 → 내 문장 말하기 |
| 말하기 세션 | 듣고 따라 말하기 → 듣고 고르기 → 질문에 답하기 → (5단계부터) 역할극. 마이크 버튼을 누르고 말하면 글자로 바뀌어 비교해 준다 |
| 세션 결과 | 별(끝까지 1 · 다시 도전 1 · 그날 복습 1), 오늘 얻은 단어, 단원 진행 칸, 오늘의 한 문장 |
| 복습(2차) | 홈의 '복습 2분' 버튼. 뜻 고르기와 철자 타일 만들기, 앱이 채점한다 |

## 부모 화면

홈 구석의 부모 메뉴에서 PIN 을 넣고 들어간다.

| 메뉴 | 내용 |
|---|---|
| 진도 | 영역별 단계 · 단원, 최근 기록(쓴 글, 말한 내용의 인식 텍스트), 약점 |
| 조정 | 단계 · 단원 올리기 · 내리기. 자동 승급은 기록에 남고 되돌릴 수 있다. 보강이 4회를 넘으면 여기에 확인 표시가 뜬다(다음 단원 · 한 번 더 · 단계 내리기 가운데 선택, 3일 안에 고르지 않으면 다음 단원) |
| 설정 | 기본 4개(세션 길이 · 관심 주제 · 실물 보상 별 개수 · 쉬는 날). 나머지는 고급 화면, 다음 단원부터 적용 |
| 수업 미리보기 | 다음 단원의 수업을 읽어 보고 다시 만들기 |
| AI 사용량 | 이번 달 비용, 예산 80% 경고 |
| 보상 | 실물 보상 등록(이름 · 필요한 별 개수), 홈에 목표로 보인다 |
| 알림 | 수업 버퍼 부족, 생성 실패, 음성 인식 대체 모드 반복 |

## 문제가 생겼을 때

| 상황 | 앱이 하는 일 | 부모가 할 일 |
|---|---|---|
| 마이크가 안 된다 | 듣고 고르기 · 단어 카드 대체 모드로 진행, 5회 이어지면 알림 | 브라우저 마이크 권한을 켠다(앱이 설정 경로를 그림으로 보여 준다) |
| 수업이 없다 | 1회분을 바로 만들고 뒤에서 단원 전체를 다시 준비 | 부모 화면 알림을 본다 |
| 선생님 답장이 안 온다 | 다음 앱 진입 때 다시 부른다. 아이에게는 '아직 읽고 있어요' | 기다린다 |
| AI 예산을 넘었다 | 역할극 · 질문 답 · 첨삭을 다음 날로 미루고 준비된 수업만 진행 | 고급 설정에서 예산을 본다 |
| 접근 코드를 잊었다 | 서버 환경 변수를 바꾸면 모든 기기에서 새 코드를 넣는다 | 개발 환경 설명서 참고 |

## 지원 기기

| 브라우저 | 음성 인식 | 읽어 주기 |
|---|---|---|
| Chrome · Edge(Windows · macOS) | 된다 | 된다 |
| Chrome(Android 태블릿) | 된다 | 된다 |
| Safari(iPadOS 17 이상) | 된다 | 된다 |
| Firefox, iPad 의 다른 브라우저 | 안 된다, 대체 모드 | 브라우저마다 다르다 |

아이의 음성은 앱이 저장하지 않는다. Chrome 은 음성을 Google 서버로 보내 글자로 바꾼다. 쓴 글과 인식된 글자는 Anthropic 으로 보내 첨삭 · 평가를 받고, 원문은 12개월 뒤 지운다.
