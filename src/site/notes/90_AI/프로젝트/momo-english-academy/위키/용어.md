# 용어

문서 · 코드 · 화면에서 같은 말을 쓴다. 요청자 지시(2026-10-15)로 "트랙" · "유닛"은 쓰지 않는다.

| 용어 | 뜻 | 쓰지 않는 말 |
|---|---|---|
| 영역 | 읽기 · 쓰기 · 말하기(· 회화 제안). 단계 · 단원 · 승급이 각각 돌아가는 단위 | 트랙, 스킬 |
| 단계 | 영역 안 1~12. CEFR 한 등급이 3단계 | 레벨 |
| 단원 | 단계 안 5개. 문법 1개 + 어휘 30개 안팎, 준비 수업 13회(새 단어 배정 8 + 다지기 5) · 최소 8회(편집자 값, [[90_AI/프로젝트/momo-english-academy/위키/결정/결정-목록\|결정-목록]]) | 유닛 |
| 수업 | 단원 안에서 미리 생성해 둔 1회분 내용 | 레슨 |
| 세션 | 아이가 수업 1회를 실제로 하는 5~8분 | |
| 활동 | 세션 안의 차례(새 단어 → 지문 → 문제 …). 1회차 B1-32 | 스텝, 단계(겹침) |
| 숙달 | 승급 판정 기준. 어휘는 앱 채점으로 '알아봄' · '씀' 두 상태(잠정) | |
| 승급 | 단원 5개 통과 뒤 단계 평가 80% 로 다음 단계 | 레벨업 |
| 보강 수업 | 통과 기준 미달 때 약한 어휘 · 문법으로 만드는 수업 1회분 | |
| 다지기 수업 | 단원 안에서 새 단어 없이 앞서 배정한 단어를 다시 쓰는 수업(단원당 5회). 단어장 복습과 헷갈리지 않게 붙인 이름 | 복습 수업 |
| 선생님 답장 | 첨삭이 미뤄졌다가 오면 홈에 붙는 포스트잇. 다음 쓰기 세션은 '지난번에 쓴 글'로 연다 | |
| 보관 · 폐기 | 준비 수업의 상태. 부모가 단계를 조정하면 보관(다시 들어가면 재사용), 재생성 · 조기 통과 때 폐기 | |
| 버퍼 | 현재 단원 잔여분 + 다음 단원 전체가 준비된 상태(2~3주) | |
| 배치 평가 · 단계 평가 | 시작 단계를 정하는 평가 · 승급 평가(20문항) | 레벨 테스트 |
| 생각 꺼내기 | 쓰기 6단계부터 쓰기 전 AI 가 한국어로 2~3개 묻는 짧은 대화 | |
| 오늘의 한 문장 | 그날 아이가 만든 문장 하나를 홈에 붙이는 것(1일 1아웃풋) | |
| 토리 | 회화 영역(제안)의 AI 친구 다람쥐 | |
| recast | 틀린 말을 바른 말로 자연스럽게 되풀이해 주는 피드백(회화 1~4단계) | |
| 포스트잇 보드 | 디자인 방향 B. 코르크 바탕, 노랑 읽기 · 하늘 쓰기 · 분홍 말하기 · 초록 회화 | |
