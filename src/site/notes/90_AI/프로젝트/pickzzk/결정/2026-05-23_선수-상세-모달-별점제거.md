# 실력 별점(★) 제거 + 선수 상세 모달 + AI 평가 디자인

> 2026-05-22 저녁(커밋은 23일 새벽) 세션. "실력 지표 별표시가 모호하다"는 지적에서 출발해, 별점을 없애고 그 자리에 선수 상세 모달을 붙였다. 덤으로 AI 평가가 데이터 덩어리로 나오던 버그도 고침.

## 배경

선수 카드에 실력을 별(★ 0~5)로 보여주고 있었는데, 이 별이 뭘 근거로 한 건지 모호했다. 실제로 코드를 보니 ① 별로 바꾸는 규칙이 화면마다 3가지로 제각각(중복 구간까지 있어 점수가 달라도 별이 같음)이고, ② 별의 바탕인 실력 점수(rating) 자체가 아직 진짜 데이터가 아니라 임시값(전 선수 50)이라 의미가 없었다. CLAUDE.md상 실력 평가는 "시뮬 결과 + 시청자 별점 누적"이 최종 출처인데 그게 아직 안 엮인 상태.

또 모의 드래프트의 선수 "상세" 버튼을 누르면 뜨는 상세 창의 "AI 평가"가 디자인 없이 `{ "playStyle": [...], "hook": ... }` 같은 데이터 덩어리(JSON)로 통째로 나왔다.

## 결정

- **실력 별점(★) 전면 제거** — 홈 카드(매물 시세/픽 순서)·모의 드래프트·경매 화면 전부. 근거 없는 별이라 패치보다 제거. **단, 팀장 표시 ★는 유지** — 그건 "이 선수가 팀장"이라는 역할 마커라 의미가 명확하다(실력 별점과 다른 것).
- **별 자리에 선수 상세 모달** — 별 대신, 선수를 클릭하면 롤 계정·솔로랭크 티어·모스트 챔피언·AI 평가가 담긴 상세 창이 뜬다.
  - 홈 매물시세/픽순서 카드 클릭 → 상세 모달(시청자 화면이라 PICK 버튼 없는 read-only).
  - 모의 드래프트 선수 카드 클릭 → 상세 모달(드래프트라 PICK 가능). 기존의 별도 "상세" 버튼은 없애고 카드 클릭 하나로 통일.
- **AI 평가 버그 수정** — AI 평가 데이터가 객체인데 화면에 그대로 찍어서 JSON 덩어리로 보였다(객체를 그대로 출력하면 그렇게 된다). 한 줄 요약·플레이 스타일 태그·강점/약점/활용으로 나눠 보기 좋게 렌더하도록 고침.

## 검증 결과

- 회귀 395건, 빌드 통과.
- 브라우저로 직접 확인: 홈 매물 시세 카드 클릭 → 상세 모달(달콤레나: 에메랄드 51% / 모스트 챔프 / AI 평가 깔끔). 모의 드래프트 카드 클릭 → 상세 모달 + PICK. 경매 화면 실력 별 사라짐(팀장 ★만 남음). 콘솔 오류·경고 0.
- 솔로랭크 데이터는 `fetch:riot`(배치)로 채운 선수만 값이 있고, 안 채운 선수는 모달에 "미수집"으로 나온다(깨지지 않음).

## 결과 / 영향 / 다음에 조심할 것

- 시청자 입장: 근거 없는 별 대신, 선수를 누르면 실제 솔로랭크·모스트 챔프·AI 평가를 본다.
- 다음에 조심할 것:
  - "버튼(트리거) 제거"와 "기능(모달) 제거"는 다르다. 이번에 "드래프트 상세 버튼 없애줘"를 모달 자체를 들어낸 걸로 과하게 해석했다가, "드래프트에도 상세 모달은 필요"라고 해서 카드 클릭으로 되살렸다.
  - 객체 데이터를 화면에 쓸 땐 그대로 찍으면 JSON으로 덤프된다 — 항상 필드별로 렌더.
  - 같은 ★ 글자라도 "실력 지표"와 "팀장 마커"는 다른 것. 제거 범위를 정확히 한정할 것.
