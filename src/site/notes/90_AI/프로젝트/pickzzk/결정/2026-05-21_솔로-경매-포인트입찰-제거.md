# 솔로(혼자) 경매에서 포인트 입찰 방식 제거 — 솔로 경매 = 자유 픽 단일

> 2026-05-21 세션. 혼자서 굴려보는 모의 경매(솔로)에서 "포인트를 걸고 입찰하는" 방식이 너무 불편해서 아예 없애기로 했다. 솔로 경매는 이제 포인트 없이 매물을 자유롭게 배정하는 "자유 픽" 하나만 남는다. 포인트 입찰의 재미는 여러 명이 함께 들어와 실시간으로 경쟁하는 "멀티"에서만 즐길 수 있다.

## 배경 — 왜 "쓰레기 같다"고 느꼈나

시청자가 혼자 모의 경매를 돌려볼 때 쓰던 "포인트 입찰" 방식(코드에서는 auction-sim)을 실제 사용자 경로로 끝까지 돌려보니, 구조 자체가 답답했다.

1. **"패스" 버튼이 두 가지 의미를 겸했다.** 내가 가장 높은 금액(예: 55포인트)을 불러도, 다른 팀들이 다 "패스"하고 + 나까지 한 번 더 "패스"를 눌러야 비로소 낙찰이 확정됐다. "내가 55포인트 걸었는데 왜 또 내 차례가 오지? 낙찰된 거 아닌가?"라는 혼란이 그대로 생긴다. 실제 자낳대 경매는 타이머와 부저가 "낙찰" 신호인데, 최고 입찰자가 스스로 패스를 눌러 확정하는 건 직관에 정면으로 어긋난다.
2. **4팀을 전부 혼자 클릭해야 했다.** 매물 하나에 최소 다섯 번(입찰 1 + 다른 팀 패스 3 + 확인 패스 1), 16개 매물이면 80번 넘게 눌러야 한다. 게다가 "어느 팀이 나"인지 구분도 없었다.
3. **한 번 패스하면 그 매물에서 영구 제외**되는데 되돌릴 방법이 없고, 패스를 눌러도 화면에 아무 반응이 없어 클릭이 먹혔는지조차 알기 어려웠다.

고치는 방향(예: 내 팀만 고르고 나머지는 AI가 자동 입찰, 최고가면 자동 낙찰 등)도 검토했지만, **그냥 없애는 게 낫다**는 결론을 내렸다. 혼자 포인트 입찰 경매를 굴리는 것 자체가 재미가 없는 구조였기 때문이다.

## 결정

- **솔로 경매 = "자유 픽"(코드명 sandbox) 하나만.** 포인트도 차례 강제도 없이 매물을 드래그하거나 팀을 골라 자유롭게 배정한다.
- **포인트 입찰 경매는 멀티 전용.** 방 코드로 여러 명(또는 빈 자리는 AI)이 들어와 타이머 안에서 실시간으로 경쟁 입찰하는, 진짜 자낳대 방식만 남긴다.
- 진입 화면(entry)에서 솔로를 고르면 더 이상 "경매 시뮬 / 자유 픽" 토글이 없고, "자유 픽"이라는 안내만 보인다.

## 검증 결과

- 단위·빌드: lint 0, 단위 테스트 381개 통과(삭제된 솔로 엔진 전용 36개 빠짐), 빌드 정상.
- 솔로 경매 진입 → 자유 픽 화면으로 바로 가는 것 확인(P0 스모크 7개 통과, 화면 폭 375·768·1440 넘침 없음, 콘솔 오류·경고 0).
- 멀티 경매 끝까지 실사용 검증: 방 생성 → 로비 → 입찰(직접 한 번 낙찰) → 16개 전부 낙찰 → 결과 저장 → 홈 반영까지 정상, 콘솔 0. 솔로 입찰 엔진을 들어내도 멀티 동작은 그대로(코드상으로도 멀티는 항상 멀티 엔진만 쓰고 있었음)임을 확인.

## 결과 / 영향 / 다음에 조심할 것

- 시청자 입장: 혼자서는 "내가 짠 팀이 어떻게 굴러갈지" 가볍게 자유 배정으로 보고, 입찰 경쟁의 재미는 친구·시청자와 함께 멀티에서 즐기는 식으로 역할이 깔끔하게 갈렸다.
- 코드: 솔로 입찰 엔진(`useMockAuctionState`, 592줄)과 그 전용 회귀 테스트를 삭제했다. 경매 보드(`MockAuctionBoard`)는 멀티 전용이 됐다.
- 과거에 박았던 "솔로 경매에 두 가지 모드(자낳대 정합/자유 픽)" 결정은 폐기됐다. 앞으로 솔로 경매를 다시 논의할 땐 "자유 픽 단일"이 기준이다.
- 멀티 경매 자동진행 도우미(autoplay)는 멀티(타이머 자유 입찰)와는 원래 맞지 않는다(턴 기반 가정). 이번 변경과 무관한 기존 한계이며, 멀티 자동 검증은 별도 방식이 필요하다.
