# 경매 팀장 정리 — 매물 시세에서 팀장 빼기 + 죽은 코드 + 시뮬 횟수 표시 제거

> 2026-05-22 세션. 팀장제 경매에서 "팀장이 매물 시세에 의미가 있냐"는 질문에서 출발해, 잘못 끼어 있던 표시와 옛 정책 잔재를 정리했다.

## 배경

팀장제 경매에서 팀장은 **포인트로 선수를 사는 쪽(뽑는 사람)**이지, 포인트를 받고 팔리는 매물이 아니다. 그런데 활성 홈의 "매물 시세" 목록에 팀장이 같이 끼어 있었다. user 가 "뽑히는 사람의 가격이 시세인데 팀장은 포인트로 안 뽑히잖아, 매물 시세에 있을 이유가 없다"고 지적했다. 또 각 매물 카드에 붙던 "시뮬 N회"는, 시뮬 결과가 충분히 쌓여 가격이 갈리기 전엔 전 선수가 같은 값이라 정보가 없었다.

추가로, 예전(2026-05-17)에 폐기한 "팀장 몸값을 팀 예산에서 깎는" 정책의 코드가 실행되지 않는 채로 남아 있었다.

## 결정

- **팀장은 매물 시세·픽 순서 목록에서 제외한다.** 표시 목록을 만드는 곳(`usePlayerRatings`)이 팀장 명단(`captainIds`)을 걸러낸다. 경매(시세)뿐 아니라 스네이크(픽 순서)에도 같이 적용 — 팀장은 어느 룰에서든 "뽑는 사람"이라 목록 대상이 아니다.
  - 참고: 스네이크엔 "시세"가 없다. 같은 1단계 화면이 룰에 따라 경매면 "매물 시세"(가격), 스네이크면 "픽 순서"(몇 라운드에 뽑힐지)를 보여준다. 둘 다 팀장이 끼면 안 되는 건 같다.
- **"시뮬 N회" 표시 제거.** 매물 카드 / 시뮬 카드 / 요약 세 곳에서 뺐다. 단, "시뮬 대기 · N/5"(아직 평가가 준비 안 됐다는 진행 표시)는 남겼다 — 그건 "준비됨/안 됨"을 알려주는 다른 용도.
- **죽은 코드 제거.** 팀장 몸값을 팀 예산에서 깎던 분기는 항상 꺼져 있어 실행되지 않았다. user 의 "패치보다 제거" 방침대로 통째로 들어냈다(동작은 그대로 — 팀장은 공짜로 자기 팀에 들어가고 예산은 안 깎임).

## 검증 결과

- 단위 테스트: 팀장 제외 4건 신규(경매·스네이크 각각 제외 / 감독제는 전원 포함 / 명단 없을 때 안전). 폐기 정책 가드 테스트는 그대로 통과.
- 전체 회귀 395건, 빌드 통과.
- 브라우저로 직접 확인: 팀장제 경매 활성 홈에서 매물 시세가 **16개**로 나옴(4팀 × 5명 = 20명에서 팀장 4명 빠진 수). "시뮬 N회" 사라짐. 콘솔 오류 0.

## 결과 / 영향 / 다음에 조심할 것

- 시청자 입장: 매물 시세에 팀장이 안 보여 "왜 뽑는 사람이 매물에 있지?" 하는 혼란이 없어진다. 화면도 덜 시끄럽다.
- 다음에 조심할 것: "시세(가격)", "별점(실력 rating)", "픽 순서(라운드)"는 서로 다른 축이다. 이번에 처음 답할 때 시세와 별점을 섞어 말해 user 가 정정했다. 이름·지표를 다룰 땐 어느 축인지 먼저 분명히 할 것.
- "매물 시세 = 시뮬 누적 평균"은 픽지직의 핵심 컨셉(매물 평가 = 시뮬 + 시청자 별점 누적)이라 컨셉 자체는 유지. 시뮬이 5회 미만이면 임시값(전원 동일)이 나오는 건 정상 — 데이터가 쌓이면 갈린다.
