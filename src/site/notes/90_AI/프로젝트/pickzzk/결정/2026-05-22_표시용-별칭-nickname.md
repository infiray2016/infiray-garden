# 스트리머 표시용 별칭(nickname) — 모든 화면에서 별명으로 보이게

> 2026-05-22 세션. 스트리머마다 "부르기 쉬운 별명"을 정해두면 시청자가 보는 모든 화면이 그 별명으로 나오게 했다. (옵시디언 개선사항 #5)

## 배경

스트리머의 치지직 채널명이 실제로 부르는 이름과 다른 경우가 많다. 예를 들어 채널명이 "달콤레나 씨"인데 사람들은 그냥 "달콤레나"라고 부른다. 화면 곳곳(드래프트 보드, 모의 시뮬, 결과 명단, 활성 홈)에 채널명이 그대로 나오니 어색했다. 그래서 "별칭을 정하면 모든 화면에서 별칭으로 보여달라"는 요청(개선사항 #5)이 있었다.

## 결정

- 스트리머 정보에 **별칭 칸(`nickname`)** 하나를 더한다. 운영자가 스트리머 편집에서 자유롭게 적는다.
- **별칭을 비워두면 채널명으로 자동 표시**한다(= 기본값이 곧 채널명). 별칭을 채널명 복사본으로 미리 박아두지 않는 이유: 그렇게 하면 나중에 치지직에서 채널명이 바뀌어도 복사해둔 별칭이 옛날 이름에 멈춰버린다. "비었으면 채널명"으로 두면 채널명이 바뀌어도 자동으로 따라간다.
- 화면에 이름을 보여주는 곳이 여기저기 흩어져 제각기 채널명을 읽고 있었는데, **표시 이름을 정하는 함수 한 곳(`displayName.js`)으로 모았다.** 앞으로 "어디서 어떤 이름을 보여줄지"는 이 한 곳만 보면 된다.
- **중요한 구분**: 별칭은 "사람에게 보여주는 라벨"에만 쓴다. 경기 스크린샷을 읽어 선수를 맞추는 자동 인식(OCR)은 **라이엇 게임명**(라이엇 ID에서 #태그 뗀 부분)을 핵심 매칭 키로 쓴다(채널명·alias는 보조 타겟). 스크린샷엔 채널명이 아니라 라이엇 게임명이 찍히기 때문. 그 매칭 필드(scrimMapping/scrimPlayerMatch)에 별칭을 섞으면 인식이 깨지므로 안 건드린다.
- 스트리머 DB 관리 화면처럼 별칭을 *설정하는* 화면에서는, 별칭을 크게 보여주되 별칭이 설정된 경우 원래 채널명을 작게 같이 보여줘 운영자가 누구인지 헷갈리지 않게 했다.

## 검증 결과

- 단위 테스트 10건(별칭 우선 / 빈 값·공백 폴백 / 미설정 안전 / null 폴백) 통과.
- 전체 회귀 391건, 빌드, 모의 시뮬 7건 모두 통과.
- 브라우저로 직접 확인: 스트리머 DB 목록 정상, "달콤레나 씨" 편집 모달에 별칭 칸이 뜨고(빈 칸이면 "달콤레나 씨"로 보인다는 안내 포함), 콘솔 오류 0. (실제 저장은 공유 DB라 테스트 데이터 안 넣고 화면 확인까지만)

## 결과 / 영향 / 다음에 조심할 것

- 시청자 입장: 모든 화면에서 익숙한 별명으로 선수를 알아볼 수 있다.
- 운영: 스트리머 편집에서 별칭만 적으면 끝. 안 적으면 채널명 그대로.
- 다음에 조심할 것: "보여주는 이름"과 "인식·매칭에 쓰는 이름"은 다르다. 이름 관련 코드를 만질 때 둘을 섞지 말 것. (스크림 OCR 매칭의 핵심 키 = 라이엇 게임명, #태그 제거. 채널명은 보조 타겟이라 채널명==게임명일 때만 우연히 맞음 — 별도 점검 여지)
