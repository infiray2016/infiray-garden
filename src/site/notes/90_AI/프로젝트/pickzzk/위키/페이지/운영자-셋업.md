# 운영자 셋업

> 토너먼트 새로 박거나 / 활성 토너먼트 룰 변경. **자유 설정** — 변경 가능 (stage 진행 후엔 보호).

## URL / 뷰

- URL: `/admin/setup`
- View: `src/views/admin/SetupView.vue` (또는 admin views/ 안)
- 권한: admin only (`useAdminGate`)

## 박는 흐름

```
1. 대회 기본 (name / season / startsAt / endsAt)
   ↓
2. 셋업 룰 (자유 설정 — 축별 독립)
   ↓
3. 출전 명단 cherry-pick (streamersDB 에서)
   ↓
4. 검증 (룰 정합성 / 명단 충분?)
   ↓
5. 셋업 완료 → stage advance (pre-launch → pre-open 등)
```

## 1) 대회 기본

- `name` — 호종컵 5기 / 자낳대 시즌 X 등
- `season` — "2026 SUMMER" 등
- `seasonNumber` — 5
- `game` — `lol` | `ow`
- `startsAt` / `endsAt` — ISO datetime
- `publicDraftAt` — 공개 드래프트 일자 (사전 내전 진입 시점)

## 2) 셋업 룰 (자세히는 [[90_AI/프로젝트/pickzzk/위키/셋업-룰\|셋업-룰]])

> 축별 독립 — fixed enum 폐기. 운영자가 자유 박음.

### 픽 / 룰 축

- **`teamCount`** — 가변 (4 / 6 / 8 / ...)
- **`picksPerTeam`** — 팀당 픽 수 (LoL 5 / OW 5+)
- **`pickRule`** — `snake` (스네이크 드래프트) / `auction` (포인트 경매)
- **`pickAuthority`** — `coach` (감독제) / `captain` (팀장제)

### 감독 처리 (captain 시만)

- **`coachAssignment.mode`** — 4 종:
  - `none` — 감독 자리 없음
  - `auction-lot` — 감독도 매물로 경매
  - `lottery` — 감독 추첨 (본선)
  - `remaining-points` — 잔여 desc 감독 선택
- `coachAssignment.timing` — `pre` / `post`
- `coachAssignment.order` — `random` / `auction-seed`
- `coachAssignment.tieBreak` — `coin` / `auction-seed`

### 팀장 룰 (captain 시만)

- `captainRule.occupiesPlayerSlot` — **true (fix)** — 팀장 = 출전선수
- `captainRule.budgetPolicy` — `none` (자기예산제) / `subtract-point-value` (팀장 가격 차감)

### 경매 룰 (auction 시만)

- `auctionRule.budgetPerTeam` — 팀별 예산 (1000pt 등)
- `auctionRule.bidUnit` — 입찰 단위 (5pt)
- `auctionRule.lotDurationSec` — 매물 시간 (10s)
- `auctionRule.antiSnipeExtendSec` — 마지막 N초 연장 (5s)

## 3) 출전 명단 (cherry-pick)

- `roster` — `[streamerId, streamerId, ...]`
- streamersDB (마스터 컬렉션 `streamers/{id}`) 에서 선택
- 부족한 경우 streamersDB 에서 새 박음 (운영자 [[90_AI/프로젝트/pickzzk/위키/페이지/스트리머-DB\|스트리머-DB]] 진입)
- 자동 검증:
  - teamCount × picksPerTeam ≤ roster.length
  - (captain-led 시) captainIds 모두 roster 안
  - position 분포 (LoL: Top/Jng/Mid/ADC/Sup 각 N+)

## 4) 검증

운영자에게 표시:
- 인원 충분?
- 포지션 분포 OK?
- captain 4 명 박힘?
- 경매 룰 누락 없음?

자동 lint:
- pickAuthority='captain' + coachAssignment.mode 미설정 → 경고
- pickRule='auction' + auctionRule.budgetPerTeam=0 → 경고

## 5) 셋업 완료 → stage advance

`finalizeRoster()` 호출:
- `rosterFinalizedAt: serverTimestamp` 박음
- stage 'pre-launch' → 'pre-open' (또는 명시 stage 로) advance
- `timelineEvents` 에 milestone 자동 push (`STAGE_AUTO_MILESTONE`)

자세히는 [[90_AI/프로젝트/pickzzk/위키/개발-흐름\|개발-흐름]] / `useTournamentSetup.js`.

## 변경 가능성

> [!info] 셋업 룰 = 자유 변경
> stage advance 전 (pre-launch 동안) 자유 변경 가능. advance 후엔 보호 (룰 갈음 시 데이터 무효화 위험).

| stage | 룰 변경? |
|---|---|
| `pre-launch` | ✅ 자유 |
| `pre-open` | ⚠ 제한적 (timelineEvents 갱신 / 명단 추가 OK) |
| `mock` | ❌ lock (모의 시뮬 룰 변경 시 누적 결과 무효) |
| `scrim` | ❌ lock |
| `final` | ❌ lock |
| `archived` | ❌ freeze |
