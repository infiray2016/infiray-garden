# 시청자 제보

> 시청자가 게임 결과 (LoL 결과창 / 전적) OCR 캡처 → 운영자 승인 큐 진입. 자세한 OCR 알고리즘은 [[90_AI/프로젝트/pickzzk/위키/기능/OCR\|OCR]].

## URL / 뷰

- URL: `/scrim/submit`
- View: `src/views/ScrimSubmitView.vue`
- 권한: 공개 (로그인 옵션 — 더 신뢰성 있는 제보 가능)

## 흐름

```
1. 시청자가 결과창 / 전적 페이지 캡쳐
   ↓
2. 업로드 (이미지 → /api/scrim-parse)
   ↓
3. Claude Vision 이 챔프 / KDA / 결과 parse
   ↓
4. 시청자가 confirm / 정정 (chip click + alias 학습)
   ↓
5. 제출 → scrimSubmissions/{id} 컬렉션 박힘
   ↓
6. 운영자가 [[제보-큐]] 승인 → scrimDays/{date}/games/ 로 promote
```

## stage 별 분리

> 같은 view 지만 stage 따라 박히는 `kind` 다름.

| stage | kind |
|---|---|
| `pre-launch` | (제보 불가) |
| `pre-open` | `inhouse` (내전) |
| `mock` | `inhouse` |
| `scrim` | `official-scrim` 또는 `unofficial-scrim` (시청자 선택) |
| `final` | `final` |
| `archived` | (제보 불가) |

## API

`POST /api/scrim-parse`:
```json
{
  "image": "base64",
  "kind": "inhouse" | "official-scrim" | "unofficial-scrim" | "final",
  "date": "YYYY-MM-DD"
}
```

→ Response:
```json
{
  "champions": [{ "name": "Aatrox", "team": "A", "position": "Top", ... }],
  "kda": [...],
  "result": "A_win",
  "championColumnBboxA": [...],
  "championColumnBboxB": [...]
}
```

자세히는 [[90_AI/프로젝트/pickzzk/위키/기능/OCR\|OCR]] / [[90_AI/프로젝트/pickzzk/위키/기능/AI-프롬프트\|AI-프롬프트]].

```json
{
  "tournamentId": "hojong-cup-5",
  "kind": "inhouse",
  "date": "2026-07-08",
  "teamA": "...",
  "teamB": "...",
  "score": { ... },

  "submittedBy": "uid | anonymous"

```

## 검증 (운영자 승인 전)

- 챔프 5+5 다 박힘?
- KDA 셀 다 박힘?
- score 유효? (3-0 / 2-1 등)
- teamA / teamB 박힘?
- duplicate 의심 X (같은 date / kind / teams 가까운 시간)

## OcrStatusFrame 패턴

> 박힘 상태별 보더 + status pill. user verbatim 박힘.

- `auto` — Claude Vision 자동 추출 (라이트 보더)
- `candidate` — 후보 여러개 (오렌지 보더)
- `unknown` — 못 박힘 (회색 보더 + warning)
- `confirmed` — user 가 확인 (초록 보더)

자세히는 `feature-game-input-ocr` 스킬 / [[90_AI/프로젝트/pickzzk/위키/기능/OCR\|OCR]].

## 헷갈리는 점

> [!warning] 시청자 제보 ≠ 운영자 업로드
> - **시청자 제보** (이 페이지) = 큐 → 운영자 승인 필요
> - **운영자 업로드** [[90_AI/프로젝트/pickzzk/위키/페이지/게임-업로드\|게임-업로드]] = 즉시 반영

> [!warning] 결과창 챔프 = 한글 text OCR primary
> user verbatim (`feedback_champion_text_ocr_primary.md`):
> "결과 스크린샷 챔프는 한글 텍스트 OCR 1차, ONNX classifier 는 cross-check / fallback"

> [!warning] 시청자 = 정체성 / 운영자 = 부수
> [[90_AI/프로젝트/pickzzk/위키/개요\|개요]] 의 user 정체성. 시청자가 시청 재미용 만든 트래커.

> [!warning] 비공식 스크림 = 일정 X
> 사전 등록 일정 외의 스크림. `scrimScheduled/` 안 박힘. OCR 제보만으로 박힘.
