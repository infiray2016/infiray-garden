# 모의 경매

> 포인트 경매 시뮬 페이지. solo (manual) / multi (방 기반) 두 모드 + manual 안 sub-mode (`auction-sim` / `sandbox`). 자낳대 정합.

## URL / 뷰

- URL: `/mock/auction`
- Query: `?phase=sim` = entry 거치지 않고 board 직진입 (dev / debug)
- Query: `?seedDemo=1` = mockResults sessionStorage demo seed (R21 C5)
- View: `src/views/MockAuctionView.vue`
- 권한: 공개 (시청자)

## phase

```
phase 'entry'   → MockEntryShell (모드 / 룰 / 닉네임 박음)
phase 'sim'     → MockAuctionBoard 또는 MockAuctionSandbox
```

진입 시 `phase='entry'` default. 사용자가 `시작` 박으면 `'sim'`.

## 모드 매트릭스

```
manual (수동 4 감독 직접)
├── auction-sim (자낳대 정합 — 포인트 + 입찰 + 유찰 + 자동 배정)
└── sandbox (자유 픽 — 포인트 X + drag/click)

multi (방 기반)
└── auction-sim only (sandbox 멀티 미지원)
```

## MockEntryShell — 진입

`src/components/mock/MockEntryShell.vue`:

1. **셋업 strip** — 대회 / 룰 / 팀 / 시작 pt / 매물 시간 표시
2. **모드 picker** — `방 기반 (혼자도 가능)` vs `수동 (4 감독 직접)`
3. **닉네임 박음** — sessionStorage 의 기존 값 prefill
4. **multi 분기** — `MockRoomEntry` (방 만들기 / 참가) → `MockAuctionLobby` (자리 claim / 룰 옵션)
5. **manual 분기** — `auction-sim` vs `sandbox` sub-mode picker + 시작 버튼

### multi sub-phase

```
multi:
  room → lobby → (시작 시 emit 'start')

  room  = MockRoomEntry (방 만들기 / 참가)
  lobby = MockAuctionLobby (4 자리 claim + 팀별 시작 pt + 4 룰 옵션 + 시작 버튼)
```

### manual sub-mode

- `auction-sim` (자낳대 정합) → `MockAuctionBoard`
- `sandbox` (자유 픽) → `MockAuctionSandbox`

## MockAuctionBoard — 진행 화면

`src/components/mock/MockAuctionBoard.vue`. engine 분기:
- `mode='manual'` → `useMockAuctionState`
- `mode='multi'` → `useAuctionMultiState`

같은 surface (adapter 필드) 라 UI 코드 분기 최소 (5 곳).

### 구성

```
<MockAuctionBoard>
├── 헤더 (대회 / 모드 / 내 감독 / 나가기)
├── <PhaseStrip> (auction → coach-selection → done)
├── <MockSetupStrip>
├── <MockAuctionHouse> ← 매물 카드 + timer + 입찰 버튼
├── <MockAuctionCoachSelection> ← phase='coach-selection' 시
├── <MockAuctionTeamCards> ← 4 팀 보드
├── <MockAuctionHistory> ← 낙찰 이력
└── <MockBottomBar> (undo / reset — multi 시 disabled)
```

### MockAuctionHouse 핵심

- 매물 정보 (이름 / 포지션 / 별점) — 시세 line 폐기
- 현재 입찰가 + 입찰자
- timer (multi 시) — ⏱ N초 + progress bar + 마지막 5 초 `is-imminent`
- 입찰 버튼 `+5 / +50 / +100 / 수동` (현재가 기준 증분)
- 본인 최고가 시 = 비활성 + "내가 최고가야"
- 잔여 부족 시 = 부족한 버튼 비활성

자세히는 [[90_AI/프로젝트/pickzzk/위키/기능/멀티-경매\|멀티-경매]] / [[90_AI/프로젝트/pickzzk/위키/기능/모의-시뮬\|모의-시뮬]].

## MockAuctionSandbox — 자유 픽 (R20 C10b)

`src/components/mock/MockAuctionSandbox.vue`:
- 포인트 X
- drag/click 통합 — 매물 풀에서 팀 보드로 drag 또는 active 팀 토글 후 click
- 같은 포지션 swap
- 매물 풀 drag-back = 픽 취소
- captain 자동 픽은 swap/remove 차단
- coach 처리는 main rule 정합 (감독제 미리 박힘 / captain+auction-lot coach pool / 그 외 coach 슬롯 X)

자세히는 [[90_AI/프로젝트/pickzzk/위키/기능/모의-시뮬\|모의-시뮬]].

## 결과 저장 (mockResults v2)

시뮬 끝 시 (`isComplete=true`) `mockResults/` 에 add:
- `resultType: 'auction-sim'` 또는 `'sandbox'`
- `lots[]`, `coachAssignments[]`, `bidsSummary` (auction-sim)
- `picks[]` (sandbox)
- `source: 'multi'` 또는 `'manual'`

스키마 = [[90_AI/프로젝트/pickzzk/위키/데이터-모델\|데이터-모델]].

## composable

- `useMockAuctionState(tournament)` — solo 엔진
- `useAuctionMultiState(tournament)` — multi 엔진 (RTDB sourced)
- `useAuctionMultiRoom()` — multi 룸 인프라 (싱글톤)
- `useMockAuctionSandbox(tournament)` — sandbox 자유 픽
- `useMockResults(tournamentIdRef)` — 결과 누적
- `useAiPick.decideBid(...)` — AI 입찰 결정
- `useFormationView(tournament)` — 룰 라벨 (감독제 / 팀장제 · 잔여포인트 등)

## 헷갈리는 점

> [!warning] manual ≠ solo 한 명만
> manual = "4 감독 모두 본인이 직접" (드래프트 시뮬). turn-based 자동 진행.

> [!warning] multi = 4 시청자 자유 입찰
> turn-based 아님. timer + 동시 입찰. 자세히는 [[90_AI/프로젝트/pickzzk/위키/기능/멀티-경매\|멀티-경매]].

> [!warning] sandbox = manual only
> 멀티 sandbox 미지원. multi = auction-sim 만.

> [!warning] 시세 line 안 박음
> 매물 카드 의 "시세 N pt" line 자체 X. user 박힘 (2026-05-11).

> [!warning] phase=sim 직접 URL = debug
> `?phase=sim` 으로 entry 우회. 정상 user 흐름은 entry 거침.
