## TimelineHero — 메인 hero

> 4 step (사전 내전 / 모의 / 스크림 / 본선) progress + D-day + stage 별 메인 CTA. R21 C2 박힘.

### 구성
- 헤더: `대회명 · 다음 · <next milestone> · D-N`
- Progress dots: ●─●─●(now)─○─○
- CTA 버튼 (stage 별):
  - mock → `▸ 모의 경매 시작` → `/mock/auction`
  - scrim → `▸ 스크림 일정 보기` → `/scrim/schedule`
  - final → `▸ 본선 대진표` → `/scrim/schedule?kind=final`
  - pre-open → (CTA 없음 — 안내만)

### D-day
- `timelineEvents` 안 next milestone `at` 매칭 → `dDayLabel(at, now)` 산출
- 같은 날 → "오늘"
- 미래 → `D-N`
- 과거 → `D+N`
- 마지막 7일 또는 "오늘" = `is-imminent` (오렌지 배경 강조)

### composable
- `useTournamentTimeline(tournamentRef)` — `nextMilestone.at + dDayLabel` 박음 / 5 trap pattern 정합

## MockSimulatorCard — mock 단계만

> 모의 시뮬 진입 + **누적 시뮬 통계 dense block** (R21 C3 박힘).

### 정적 row (3 개)
- 진행 주체 (감독제 / 팀장제)
- 예산 / 입찰 단위 (auction 시)
- 매물 시간 (연장) (auction 시)

### Dense block (auction-sim 누적 1+ 시)
- N회 시뮬 (오렌지 배지) + 평균 낙찰가
- 포지션 mini grid (탑 / 정글 / 미드 / 원딜 / 서폿 평균)
- top 3 인기 매물 (pickedCount desc + 평균 낙찰가)

### CTA
- `▶ 경매 시뮬 시작` → `/mock/auction`
- `▶ 드래프트 시뮬 시작` → `/mock/draft`

### composable
- `useMockResults(tournamentIdRef)` — `mockResults/` 컬렉션 onSnapshot
- `useAuctionResultsAggregate(results)` — pure aggregate (포지션별 / top 인기)

## InhouseResultCard — pre-open / mock

> 내전 게임 (`kind='inhouse'`) thin summary.

### 정적
- meta = "N 게임 누적" 또는 "집계 대기"
- 최다 픽 / 밴 1순위 / 최다 캐리 (summary 있을 시)

### 빈 상태
"운영자 · 시청자 첫 내전 게임 등록 대기 중"

### CTA
"내전 전체 →" → `/scrim/day/<오늘>?kind=inhouse`

## ScrimScheduleCard — scrim

> 공식 스크림 일정 thin summary.

- 일정 list (status: upcoming / live / done)
- 빈 상태: "공식 일정 등록 대기 중"
- CTA: "전체 일정 →" → `/scrim/schedule`

## ScrimResultCard — scrim / final

> 공식 / 비공식 / 본선 결과 thin summary. `kind` prop 으로 분기.

### Kind 별 표시
- `official-scrim` — 공식 배지 (gold) / "공식 스크림 결과"
- `unofficial-scrim` — 비공식 배지 (orange) / "비공식 스크림 결과"
- `final` — 본선 배지 (gold) / "본선 결과"

### 빈 상태 (kind 별)
- 공식: "공식 일정 매치 결과 대기 중"
- 비공식: "비공식 스크림 결과 대기 중"
- 본선: "본선 첫 게임 결과 대기 중"

### CTA → `/scrim/day/<오늘>?kind=<kind>`

## FinalBracketCard — final

> 본선 대진표 thin summary.

- format 라벨 (더블 엘리미 / 풀리그 / 단일 엘리미 / 하이브리드)
- 빈 상태: "대진표 확정 대기 중"
- CTA: "전체 대진표 →" → `/scrim/schedule?kind=final`
