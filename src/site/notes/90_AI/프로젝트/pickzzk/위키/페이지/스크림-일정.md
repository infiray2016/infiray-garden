# 스크림 일정 (운영자)

> 공식 스크림 매치 사전 등록. `scrimScheduled/{id}` 박힘. scrim 단계의 [[90_AI/프로젝트/pickzzk/위키/페이지/활성-홈\|활성-홈]] 의 ScrimScheduleCard 가 사용.

## URL / 뷰

- URL: `/admin/schedule`
- View: `src/views/admin/ScheduleView.vue` (또는 admin views/)
- 권한: admin only

## 박는 것

```js
scrimScheduled/{matchId}: {
  tournamentId: "hojong-cup-5",
  category: "official",
  when: "2026-07-10T19:00:00+09:00",
  teamA: "분당불꽃",
  teamB: "강남수호자",
  status: "upcoming" | "live" | "done",
  score?: { ... },
  ...
}
```

자세히는 [[90_AI/프로젝트/pickzzk/위키/데이터-모델\|데이터-모델]].

## 흐름

```
1. /admin/schedule 진입
   ↓
2. 새 매치 박음 (date / time / teamA / teamB)
   ↓
3. scrimScheduled/ 컬렉션에 add
   ↓
4. 활성 홈 ScrimScheduleCard 자동 표시 (onSnapshot)
   ↓
5. 매치 진행 후 status 갱신 ('upcoming' → 'live' → 'done')
   ↓
6. 게임 결과 → /admin/scrim/upload 또는 /scrim/submit 통해 박힘
```

## 공식 vs 비공식

> [!info] 비공식 = 즉흥 (일정 X)
> user verbatim: "팀이 정해진 후 정해진 일정 외의 스크림이 비공식 스크림"

- 공식 = 사전 등록 (`/admin/schedule` 박힘)
- 비공식 = 등록 X. OCR 제보 / 결과만 박힘 (kind='unofficial-scrim')

## 호종컵 정기 cadence

- 매주 X 요일 19:00 ~ 23:00 정기
- 운영자가 미리 박음 (월 1 회 batch)

## composable

- `useScheduleList(tournamentIdRef)` — 일정 list onSnapshot
- `useAdminGate()` — 권한 체크

## status 전환

```
upcoming → live → done
   ↑          ↓
   └─ delete (운영자 cancel)
```

- `upcoming`: 사전 등록 (시간 미래)
- `live`: 진행 중 (시간 도래 + 운영자 박음)
- `done`: 끝남 (결과 박힌 후 자동 또는 운영자 박음)

## 활성 홈 표시

scrim 단계 진입 시 ScrimScheduleCard 에 표시:
- upcoming 매치 top 4 박힘
- live 매치 강조 (red 배지 — 폐기 검토)
- done 매치는 score 표시

자세히는 [[90_AI/프로젝트/pickzzk/위키/페이지/활성-홈\|활성-홈]] 의 ScrimScheduleCard.

## 헷갈리는 점

> [!warning] 비공식 스크림 = 일정 X
> 비공식은 사전 등록 안 함. OCR 제보만으로 박힘.

> [!warning] /admin/schedule ≠ /scrim/schedule
> - **/admin/schedule** (이 페이지) = 운영자 사전 등록
> - **/scrim/schedule** = 시청자 read-only 일정 보기 (TBD — 별 view 박힌 거 확인 필요)

> [!warning] scrim 단계만 활성
> stage='scrim' 일 때만 활성 홈 카드 표시. pre-open / mock / final 에서는 X.
