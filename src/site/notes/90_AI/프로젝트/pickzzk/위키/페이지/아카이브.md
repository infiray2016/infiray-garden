# 아카이브 (시즌별)

> 종료된 시즌 (`stage='archived'`) 의 모든 결과 모아 보기. read-only. legacy DraftPick 패턴을 v2 정합 박음.

## URL / 뷰

- URL: `/archive/:tournamentId` (예: `/archive/hojong-cup-4`)
- View: `src/views/ArchivePage.vue`
- 권한: 공개 read-only

## 진입 source

- 시청자 nav `아카이브 (ARCHIVE)` 클릭 (가장 최근 archived 시즌으로)
- 외부 link 공유

## 표시 내용 (R20 C8 박힌 7 컴포넌트)

```
ArchivePage (`/archive/:tournamentId`)
├── ArchiveHeader              ← 시즌명 / 기간 / 우승팀
├── ArchiveTimeline            ← 시즌 milestone (모의 / 스크림 / 본선 / 종료)
├── ArchiveTeams               ← 4 팀 final lineup + 감독
├── ArchiveBracket             ← 본선 대진표
├── ArchiveScrimResults        ← 공식 / 비공식 스크림 결과 summary
├── ArchiveInhouseResults      ← 내전 (pre-open / mock 단계) 결과
└── ArchiveStats               ← 시즌 통계 (avg 픽 / 인기 챔프 / MVP 등)
```

자세히는 `src/components/archive/`.

## 데이터 source

- `tournament` = `tournaments where stage='archived' && id=:id`
- `games` = `scrimDays/.../games` where `tournamentId=:id`
- `mockResults` = `mockResults where tournamentId=:id` (시즌 통계용)

자세히는 [[90_AI/프로젝트/pickzzk/위키/데이터-모델\|데이터-모델]].

## composable

- `useArchive(tournamentIdRef)` — 시즌 데이터 묶음
- `useArchivedTournament()` — 가장 최근 archived 자동 진입 (nav default)
- `aggregateGames(games)` — 시즌 통계 aggregate

## 시즌 종료 (archived 박는 시점)

운영자가 `stage advance` → `final` → `archived` 박음:
- `timelineEvents` 에 `season-closed` push
- `endsAt` 박힘
- 더 이상 cron / 자동 폴링 안 함 (비용 0)
- 활성 홈 진입 시 안 보임 (CLOSED 또는 다음 시즌 fallback)

## 시즌 비교

> 시즌 거듭하며 누적 — streamersDB (마스터) / mockResults / scrimDays 다 보존.

archived 페이지에서 시즌 간 비교:
- 같은 streamer 시즌별 KDA 변화
- 시즌별 인기 픽 / 밴 챔프 비교
- 시즌별 우승팀 / MVP

(이런 기능은 후속 작업 — TODOS 참조)

## 헷갈리는 점

> [!warning] 아카이브 ≠ 활성 홈
> activeStage 4 종 (pre-open / mock / scrim / final) 의 결과 = 활성 홈. archived = 별도 페이지.

> [!warning] :tournamentId 필수
> 가장 최근 archived 자동 추정 = nav 기본 동작. 명시 URL 사용 = direct link.

> [!warning] 종료 후 데이터 freeze
> archived 진입 후 결과 변경 X (운영자도 안 박음). 정정 필요 시 reactivate (스크 룰 외).

> [!warning] cron OFF 시기
> archived 시기 = 모든 자동 폴링 OFF (호종컵 cadence 3-4 개월 휴면).
