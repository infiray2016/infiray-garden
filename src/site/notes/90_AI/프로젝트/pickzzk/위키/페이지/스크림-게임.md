# 스크림 게임 (시청자)

> 게임 1 개 detail. picks / bans / KDA / MVP / 결과 / 시리즈 컨텍스트. read-only.

## URL / 뷰

- URL: `/scrim/games/:gameId` (예: `/scrim/games/g_2026-07-08_abc123`)
- View: `src/views/ScrimGameView.vue`
- 권한: 공개 read-only

## 진입 source

- [[90_AI/프로젝트/pickzzk/위키/페이지/스크림-DAY\|스크림-DAY]] 의 시리즈 row click
- 활성 홈 의 ScrimResultCard / FinalBracketCard 매치 row click
- 아카이브 의 시즌 결과 row click
- 외부 link 공유 (deep link)

## 표시 내용

```
헤더: <date> · <kind> · <teamA> vs <teamB>
├── score (3-0 / 2-1 등)
├── 시리즈 컨텍스트 (이 게임이 시리즈의 몇 번째 게임?)
├── 시리즈 안 다른 게임 navigator
├── picks / bans (5+5 각 팀)
├── KDA 표 (10 명)
├── MVP
└── 메타 (source: admin / submission, approvedAt)
```

## 데이터 source

`collectionGroup('games')` 사용 → 어느 scrimDay 든 gameId 로 직접 접근.

```js
db.collectionGroup('games').where('id', '==', gameId).limit(1)
```

자세히는 [[90_AI/프로젝트/pickzzk/위키/데이터-모델\|데이터-모델]] 의 `scrimDays/{date}/games/`.

## firestore rules (R20 C13)

```js
match /{path=**}/games/{gameId} {
  allow read: if true;       // public read
  allow write: if false;     // admin 만 (subcollection rule 따로)
}
```

collectionGroup 정합 위해 박힘.

## 시리즈 컨텍스트

> 시리즈 = 같은 teams + 가까운 시각 (1 시간 내) 게임 묶음 (자동).

- 시리즈 내 다른 게임 link (이전 / 다음)
- 시리즈 score (예: "현재 시리즈 1-1")
- 시리즈 final 게임 표시 (kind='final')

## 박힌 R 시리즈

- R20 C7.7 — `/scrim/games/:gameId` ScrimGameView (시청자 read-only) `fc59fa6`
- R20 C13 — Firestore rules collectionGroup games read-only

## 헷갈리는 점

> [!warning] 시청자 = read-only
> picks / KDA 정정은 운영자 [[90_AI/프로젝트/pickzzk/위키/페이지/스크림-DAY-편집\|스크림-DAY-편집]] 또는 user 가 [[90_AI/프로젝트/pickzzk/위키/페이지/시청자-제보\|90_AI/프로젝트/pickzzk/위키/페이지/시청자-제보]] 재제출.

> [!warning] gameId 는 globally unique
> 같은 date / teams 도 gameId 다름. collectionGroup 으로 직접 접근.

> [!warning] firestore collectionGroup 인덱스
> `firestore.indexes.json` 에 `games` collectionGroup 박힘 필요.

> [!warning] 활성 / 종료 stage 무관
> 활성 stage 끝나도 게임 detail 은 archived 단계에도 표시 가능. archived 는 별도 [[90_AI/프로젝트/pickzzk/위키/페이지/아카이브\|아카이브]] 페이지 통해.
