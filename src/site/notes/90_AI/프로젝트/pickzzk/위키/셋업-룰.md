# 셋업 룰

> 운영자가 [[90_AI/프로젝트/pickzzk/위키/페이지/운영자-셋업\|운영자 셋업]] 에서 **자유롭게 박는 토너먼트 룰**. v2 부터 fixed enum 폐기 — 축별 독립 설정.

## v1 → v2 변경 핵심

| 영역 | v1 (legacy draftpick) | v2 (pickzzk) |
|---|---|---|
| 팀 수 | **4 팀 고정** | 가변 (`teamCount` 자유) |
| 픽 룰 | snake-coach / snake-captain / auction-coach / auction-captain 4 enum | 축별 독립 (`pickRule` + `pickAuthority`) |
| 감독 처리 | coach 시 fixed, captain 시 coachMode 일부 | `coachAssignment.mode` 4 종 분기 |
| 변경 가능? | 1회 설정 후 변경 어려움 | 셋업 단계에서 자유 변경 (stage 진행 후엔 보호) |

> [!warning] "4 룰 조합" 은 옛 표현
> v1 시절 4 팀 고정 + 4 enum 표 박은 잔재. v2 는 축별 독립이라 "4 룰" 이라는 enum count 의미 없음.
> CLAUDE.md `## 4 룰 조합` 섹션 (line 47-55) = 정리 대상.

## v2 셋업 축

```
tournament: {
  // 1) 팀 / 인원 (가변)
  teamCount: number,             // 가변 (예: 4 / 6 / 8)
  picksPerTeam: number,          // 팀당 픽 수 (예: 5)

  // 2) 픽 주체 / 방식
  pickRule: 'snake' | 'auction',
  pickAuthority: 'coach' | 'captain',

  // 3) 감독 처리 (pickAuthority='captain' 시만 적용)
  coachAssignment: {
    mode: 'none' | 'auction-lot' | 'lottery' | 'remaining-points',
    timing: 'pre' | 'post',
    order: 'random' | 'auction-seed',
    tieBreak: 'coin' | 'auction-seed',
  },

  // 4) 팀장 룰 (pickAuthority='captain' 시만)
  captainRule: {
    occupiesPlayerSlot: true,           // 팀장 = 출전선수 (fix)
    budgetPolicy: 'none' | 'subtract-point-value',
    pointField: 'marketValue',
  },

  // 5) 경매 룰 (pickRule='auction' 시만)
  auctionRule: {
    budgetPerTeam: number,
    bidUnit: number,
    lotDurationSec: number,            // 멀티만 사용
    antiSnipeExtendSec: number,        // 멀티만 사용
  },
}
```

## 픽 주체 (pickAuthority)

binary — `coach` (감독제) / `captain` (팀장제).

### 감독제 (`coach`)
- 감독이 픽 주체. 감독 = 팀 (1:1 매핑).
- `coachAssignment` 미사용 (감독 = 팀, fixed).
- captain / 잔여 처리 X.

### 팀장제 (`captain`)
- 팀장 (출전선수) 이 픽 주체.
- 자동 captain pick — 팀장 본인 슬롯 점유 (`captainRule.occupiesPlayerSlot=true`).
- 감독 처리 = `coachAssignment.mode` 4 종 분기.

> [!info] "감독 모드 5 종" 은 misleading
> [[90_AI/claude/개념/메모리\|메모리]] `pick_authority_data_model.md` (2026-05-03):
> "감독 모드 5 종 misleading — 실제는 1 종 (감독제) + 4 종 (팀장제 변형)"

## 픽 방식 (pickRule)

binary — `snake` / `auction`.

### 스네이크 드래프트 (`snake`)
- 1R = 픽 순서 / 2R+ 스네이크 (정→역→정→역)
- 픽 순서는 셋업에서 조정 가능 ([[../결정/\|../결정/]] 의 picker order 결정 참고)
- 멀티 = `useSnakeMultiRoom` (R20 이전 박힘)

### 포인트 경매 (`auction`)
- 매물 = 선수 (+ 감독, `coachAssignment.mode='auction-lot'` 시)
- 자낳대 정합 입찰 모델 (timer + 자유 입찰, 멀티)
- 자세히는 [[90_AI/프로젝트/pickzzk/위키/자낳대-룰\|자낳대-룰]] / [[90_AI/프로젝트/pickzzk/위키/기능/멀티-경매\|멀티-경매]] (예정)

## 감독 처리 (coachAssignment.mode)

`pickAuthority='captain'` 시만 적용. 4 종:

| mode | 의미 | 모의 발동? |
|---|---|---|
| `none` | 감독 자리 없음 (디스코드 코치 / 외부 코칭). 2024 / 2025 자낳대 정합. | ✅ |
| `auction-lot` | 감독도 매물로 경매. 2023 s2 정합. | ✅ |
| `lottery` | 감독 추첨 (본선 시작 직전). | ❌ (본선만) |
| `remaining-points` | 잔여 desc 순서로 감독 선택. 2023 s1 정합. | ❌ (본선만) |

자세히는 [[90_AI/프로젝트/pickzzk/위키/자낳대-룰\|자낳대-룰]] 의 시즌별 매트릭스.

## 셋업에서 박는 흐름

```
1. teamCount + picksPerTeam 박음
2. pickAuthority (감독 / 팀장) 선택
3. pickRule (스네이크 / 경매) 선택
4. (팀장제 시) coachAssignment.mode 4 종 선택
5. (팀장제 시) captainRule.budgetPolicy 선택
6. (경매 시) auctionRule 4 필드 박음
7. 출전 명단 cherry-pick
8. 셋업 완료 → stage advance (pre-open / mock 등)
```

자세히는 [[90_AI/프로젝트/pickzzk/위키/페이지/운영자-셋업\|운영자-셋업]] (예정).

## 모의 발동 룰

| pickRule | pickAuthority | coachAssignment.mode | 모의? |
|---|---|---|---|
| snake/auction | coach | (N/A) | ✅ 감독제 자연 |
| snake/auction | captain | none | ✅ 감독 자리 없음 |
| snake/auction | captain | auction-lot | ✅ 감독 매물 경매 |
| snake/auction | captain | lottery | ❌ 본선만 |
| snake/auction | captain | remaining-points | ❌ 본선만 |

> [!info] 모의 = "선수가 누구와 팀이 될지 시뮬"
> lottery / remaining-points 는 대회 결과 따라 박혀서 모의에서 미리 정할 의미 X.

## 헷갈리는 점

> [!warning] "4 룰 조합" 박지 마
> legacy 잔재. v2 는 셋업 자유 설정. 축별 독립으로 박음.

> [!warning] captainRule.occupiesPlayerSlot = true (fix)
> 팀장 = 출전선수. 체크박스 X. 옵션 X. 임의 해석 X.

> [!warning] coachAssignment 는 captain-led 만
> coach-led 일 때는 미사용. 표시 redundant ('fixed' 동의어).

> [!warning] 셋업 단계 = 자유 변경
> stage advance 전엔 룰 변경 가능. advance 후엔 보호 (구체 동작은 [[90_AI/프로젝트/pickzzk/위키/페이지/운영자-셋업\|운영자-셋업]] 예정).
