# 자낳대 (자만추 LoL 대회) 룰

> "자낳대" = 자기들끼리 만들어서 한다는 LoL 시즌 이벤트 대회. pickzzk 의 baseline 도메인. 시청자에게 익숙한 룰을 그대로 따라야 자연스러움.

## 표기

- **자낳대** ← verbatim, 박은 한국어 (자내대 X / 자낣대 X)
- pickzzk 의 호종컵 = 자낳대 정합 + 호종이 시즌

## 시즌별 매트릭스 (2022 ~ 2025)

| 시즌 | 팀 수 | 픽 주체 | 감독 처리 | 잔여포인트 | 본선 룰 | pickzzk 매핑 |
|---|---|---|---|---|---|---|
| 2022 s1 | 4팀 | 감독제 | (fixed) | bracketSelection | 풀리그 + 결승 | `coach` + N/A |
| 2022 s2 | 6팀 | 감독제 | (fixed) | bracketSelection | 풀리그 + PO | `coach` + N/A |
| 2023 s1 | 6팀 | **팀장제** (원딜) | **remaining-points** (잔여 desc 감독 선택) | 감독 선택 | 풀리그 + PO | `captain` + `coachAssignment.mode='remaining-points'` |
| 2023 s2 | 6팀 | 팀장제 | **auction-lot** (감독 매물 경매) | 사용 X | 풀리그 + PO | `captain` + `coachAssignment.mode='auction-lot'` |
| 2024 s1 | 6팀 | 팀장제 | none (디스코드 코치) | bracketSelection | 풀리그 + PO + 결승 | `captain` + `coachAssignment.mode='none'` |
| 2025 s1 | 6팀 | 팀장제 | none (디스코드 코치) | bracketSelection | 풀리그 + PO + 결승 | `captain` + `coachAssignment.mode='none'` |

## 진행 흐름 (전형)

1. **참가자 모집** — 스트리머 N 명 발표
2. **경매 / 드래프트** — 4 룰 조합에 따라 (→ [[90_AI/프로젝트/pickzzk/위키/셋업-룰\|셋업-룰]])
3. **팀 확정** — 모의 시뮬 종료 시점
4. **잔여 포인트 처리** — 모드별 (감독 선택 / 대진 선택 / 사용 X)
5. **본선** — 풀리그 / PO / 결승 (`bracketFormat`)
6. **시즌 종료** — 아카이브 (`stage='archived'`)

## 핵심 메커니즘

### 매물 등장 순서 (경매)

- **랜덤 룰렛** (rating desc 아님) — user verbatim 2026-05-11
- 자낳대 영상의 룰렛 애니메이션 패턴 정합
- 우리 구현: `auctionEngine.makePrng(seed) + shuffleInPlace`

### 입찰 모델 (멀티)

- **timer + 자유 입찰** (turn-based 아님) — user verbatim 2026-05-12
- lotDuration 10초 + antiSnipe 5초 연장
- 마지막 N초 입찰 시 deadline 연장 (snipe 방지)

### 유찰 처리

- **max 2회 재경매**, 그 후 random fallback (자동 배정)
- relistQueue 에 매물 push + 큐 끝에 재추가
- 자낳대 공식 룰 그대로

### 감독 선택 (2023 s1 정합)

- 잔여 desc 많은 팀부터 1팀씩
- 4 명 후보 중 1 명 선택
- 1 round only (4 팀 = 4 selections)

## pickzzk 적용 (R20)

- C14a~d: 멀티 경매 RTDB 인프라 + UI + 트랜잭션 + coach-selection 박힘
- 자낳대 22~25 5 시즌 baseline = `docs/skills/janahdae-rules.md`
- 결정 박힘 시점:
  - 매물 순서 = 랜덤 (2026-05-11)
  - 멀티 입찰 = 자유 (2026-05-12)
  - 유찰 max 2회 + random fallback (2026-05-11)
  - 팀별 시작 pt = host 수동 입력 (2026-05-12)

## 헷갈리는 점

> [!warning] 잔여 포인트 사용처는 시즌별 다름
> - 2023 s1: **감독 선택** (remaining-points)
> - 2022 s2 / 2024 / 2025: **대진 선택** (bracketSelection)
> - 2023 s2: **사용 X** (감독도 경매)
> pickzzk 는 4 케이스 다 지원 (`coachAssignment.mode`).

> [!warning] 팀장 = 출전선수
> 팀장은 감독 X. 본인이 출전. captainRule.occupiesPlayerSlot=true (포지션 슬롯 점유).

> [!warning] 감독제 ≠ 팀장제
> - 감독제 (`pickAuthority='coach'`) = 감독이 픽 주체
> - 팀장제 (`pickAuthority='captain'`) = 팀장 (출전선수) 이 픽 주체
> 우리 v2 는 둘 다 지원, **4 룰 조합** 의 한 축.

> [!warning] 매물 순서 = 자낳대 정합 = 랜덤
> rating desc 아님. user 가 "rating desc 로 했더니 모의 안 함" 정정.
