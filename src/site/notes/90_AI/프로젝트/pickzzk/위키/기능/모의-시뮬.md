## 엔진 (snake / auction)

### snake 엔진

`src/composables/useMockDraftState.js`:
- captain 자동 픽 (occupiesPlayerSlot)
- 1R 순서 + 2R+ 스네이크
- placeBid X — 픽 directly
- `useMockDraftSandbox.js` — 자유 픽 모드 (TBD)

### auction 엔진 (solo)

`src/composables/useMockAuctionState.js` + `src/utils/auctionEngine.js`:
- PRNG seed → shuffleInPlace → 매물 순서 (random — rating desc 아님)
- buildTeams (initialBudget / teamBudgets override)
- buildQueue (선수 + auction-lot 시 감독 매물)
- eligibleTeamIdxsForLot (포지션 / 슬롯 조건)
- placeBid / passTurn / advanceTurn / finalize / advance
- relistQueue (max 2 회 + random fallback)
- coach-selection phase (remaining-points 시)

### auction 엔진 (multi)

`src/composables/useAuctionMultiState.js`:
- 같은 pure helper (`auctionEngine.js`) 재사용
- RTDB sourced (currentLot / history / relistQueue / coachSelection)
- placeBid = `runTransaction` race-safe (idx / deadline / amount 가드 + antiSnipe 연장)
- finalizeLot = effective host only
- 자세히는 [[90_AI/프로젝트/pickzzk/위키/기능/멀티-경매\|멀티-경매]].

## 시뮬 결과 → 매물 평가 산출 (R21 C8, 2026-05-15)

`usePlayerRatings v2` — 모의 시뮬 누적 결과 기반 동적 매물 평가.

**threshold = 5 회.** 미만 = "시뮬 대기 · N/5" placeholder. 이상 시 fixture 무시 + 시뮬 데이터로 산출.

| 룰 | 산출 | 정렬 |
|---|---|---|
| auction | `effectivePrice = avgSoldPrice` (시뮬 평균 낙찰가) | desc |
| snake | `score = pickRate × (totalRounds - avgRound + 1)` | desc |

**노출 위치**: `mock` stage 의 `MockMarketCard` (R20 C6 마이그 시 사라진 surface 부활).

**시그니처**:
```js
usePlayerRatings(tournamentRef, {
  auctionByPlayer,    // Map<pid, { avgSoldPrice, pickedCount }>
  snakeByPlayer,      // Map<pid, { pickedCount, pickRate, avgPickRound, avgPickIdx }>
  simSampleCount,     // { auctionSim, snakeSandbox } — threshold 판정
})
```

**출력 추가**: `effectivePrice`, `simPrice`, `simPickedCount`, `v2Active`, `simSample`.

> [!info] auction snake 산출 차이 근거 (사용자 verbatim)
> snake 단순 `avgPickIdx` 대신 `pickRate × (totalRounds - avgRound + 1)` = outlier 안정성 (5 회 sample 시 한 번 픽된 player 의 weight 문제).

> [!important] 선수 상세 모달 = 옛 DraftPick 5탭 수준 — 2026-05-24
> 선수(매물/풀 카드) 클릭 시 뜨는 상세 모달을 옛 DraftPick 사이트 구성(프로필 + 5탭: 요약/지표/AI인사이트/챔피언/최근경기)으로 다시 만들었다(v10 밝은 톤). 데이터는 3단계로 채운다: ① `fetch:riot` 가 경기별 킬관여·분당CS·데스분포·최근경기 등 세부 지표 수집 → ② `fetch:ai` 가 그걸 분석해 AI 점수·스타일 분포·강약점 생성 → ③ 모달 표시. 미수집 선수는 "수집 후 표시" 안내. 컴포넌트 `MockPlayerDetailModal.vue`, 지표 옮김 `playerStats.js(streamerStats)`, 시안 `.claude/mockups/player-detail-modal.html`. 활성 직전 `fetch:riot`+`fetch:ai` 1회로 최신화(Riot 키 24h 만료 주의). 자세히 [[../결정/2026-05-24_선수-상세-모달-rich-파이프라인\|../결정/2026-05-24_선수-상세-모달-rich-파이프라인]]

> [!important] 실력 별점(★) 제거 → 선수 상세 모달 — 2026-05-22
> 선수 실력을 별로 보여주던 표시(★)를 없앴다. 별의 바탕인 rating 이 아직 근거 없는 임시값(전 선수 동일)이라 모호했고, 별→별 변환 규칙도 화면마다 제각각이었다. **팀장 표시 ★는 역할 마커라 유지**(실력 별점과 다른 것).
> 별 대신, 선수를 클릭하면 **상세 모달**(롤 계정·솔로랭크 티어·모스트 챔피언·AI 평가)이 뜬다. 홈 매물시세/픽순서 카드 클릭(read-only, PICK 없음) + 모의 드래프트 풀 카드 클릭(PICK 가능). 기존 별도 "상세" 버튼은 카드 클릭으로 통일.
> AI 평가는 객체를 그대로 찍어 JSON 덩어리로 나오던 버그를 한 줄 요약·강점/약점/활용 등으로 구조화. 자세히 [[../결정/2026-05-23_선수-상세-모달-별점제거\|../결정/2026-05-23_선수-상세-모달-별점제거]]

> [!important] 매물 시세·픽 순서에서 팀장 제외 — 2026-05-22
> 활성 홈 1단계의 "매물 시세"(경매) / "픽 순서"(스네이크)는 **뽑히는 선수**의 평가다. 팀장은 포인트로 사는 쪽(뽑는 사람)이라 이 목록에서 빠진다(`usePlayerRatings` 가 `captainIds` 필터). 같은 화면이 룰에 따라 경매=시세(가격) / 스네이크=픽순서(라운드)를 보여줄 뿐, 팀장 제외는 양쪽 공통.
> 매물 카드의 "시뮬 N회" 표시는 제거됨 — 시뮬 데이터가 충분히 쌓여 가격이 갈리기 전엔 전 선수가 같은 값이라 정보가 없었다. "시뮬 대기 · N/5" 진행 표시는 유지.
> 또한 팀장 몸값을 팀 예산에서 깎던 옛 정책의 죽은 코드 제거(동작 변화 없음). 자세히 [[../결정/2026-05-22_경매-팀장-매물시세-제외\|../결정/2026-05-22_경매-팀장-매물시세-제외]]
