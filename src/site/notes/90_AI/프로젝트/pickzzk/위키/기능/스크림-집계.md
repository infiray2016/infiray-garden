# 스크림 집계 (aggregate)

> `scrimDays/{date}/games/{id}` 박힌 게임 데이터를 시리즈 / 시즌 / 통계로 묶어 표시. legacy DraftPick 의 핵심 인프라.

## 핵심 메커니즘

- **kind 별 분류** (`inhouse / official-scrim / unofficial-scrim / final`)
- **시리즈 자동 묶음** (같은 teams + 가까운 시각)
- **시즌 통계** (avg 픽 / 인기 챔프 / MVP / KDA)
- **collectionGroup** — 어느 date 든 직접 query 가능

## 시리즈 자동 묶음 룰

> 같은 teams + 1 시간 내 게임 = 시리즈.

```
game1: 2026-07-08 19:30  teamA vs teamB
game2: 2026-07-08 20:15  teamA vs teamB
game3: 2026-07-08 21:00  teamA vs teamB
→ 시리즈 (3 게임 묶음)

game4: 2026-07-08 22:30  teamA vs teamC
→ 별 시리즈 (다른 teams)

game5: 2026-07-09 19:00  teamA vs teamB
→ 별 시리즈 (다음 날)
```

`tests/unit/series-status.test.js` — 23 cases 검증.

## composable / utils

- `useScrimAggregate(dateRef, kindRef)` — date 별 aggregate
- `aggregateGames(games)` — pure aggregate (utils)
- `useScrimGame(gameId)` — game 1 detail
- `useArchive(tournamentIdRef)` — 시즌 archive aggregate

자세히는 `tests/unit/aggregate-games.test.js` (18 cases) / `series-status.test.js` (23 cases).

## 통계

### 게임 단위

- picks (5+5 챔프)
- bans (5+5 챔프)
- KDA (10 명)
- MVP
- score
- 시리즈 컨텍스트

### 시리즈 단위

- 게임 수
- score (3-0 / 2-1 등)
- 시리즈 MVP (KDA / damage 기준)
- 같은 챔프 픽 횟수

### 시즌 단위 (archived)

- 시즌 총 게임 수
- 최다 픽 챔프 (kind 별)
- 최다 밴 챔프
- 시즌 MVP (KDA 통계)
- 팀별 승률
- 우승팀 / 준우승 / 결승전

## 활성 홈 표시

> 카드는 thin entry — 실 detail 은 [[90_AI/프로젝트/pickzzk/위키/페이지/스크림-DAY\|스크림-DAY]] / [[90_AI/프로젝트/pickzzk/위키/페이지/스크림-게임\|스크림-게임]] / [[90_AI/프로젝트/pickzzk/위키/페이지/아카이브\|아카이브]].
