```

├── hostId: clientId

│   ├── idx, kind, subjectId, subjectName, position
```

## 룸 인프라 (useAuctionMultiRoom — C14a)

> 룸 생성 / 참가 / 자리 claim / heartbeat / 5 trap pattern.

### 액션

- `createRoom(tournamentSnapshot, auctionRule)` — host 가 룸 생성. 5 자리 code (e.g. `ABCDE`) 발급
- `joinRoom(code, nickname)` — 시청자 참가
- `claimTeam(teamIdx)` — 자리 잡기 (lobby)
- `setAuctionRule(...)` / `setTeamBudget(teamIdx, amount)` — host 만 박음
- `startAuctionInRoom({ allowUnclaimedTeams })` — host 가 시작
- `endRoom()` — host 가 종료

### Presence

- **heartbeat 3s** — 클라이언트 매 3 초 `members/{cid}/heartbeat` 갱신
- **isMemberAlive** = disconnected false + heartbeat 12s 이내
- `visible === false` 멤버 (백그라운드 탭) 는 heartbeat stale 체크 skip — Chrome throttling 방지
- `beforeunload` + Firebase `onDisconnect` — 탭 닫기 시 즉시 `disconnected: true`

### Effective host

- `aliveForegroundIds` 의 알파벳 첫 번째 = effective host
- 전원 백그라운드면 `alive` 중 첫 번째
- AI bid / finalize / advance = effective host 만 trigger

### 5 trap pattern (multi-room.md)

[[90_AI/claude/개념/하네스\|하네스]] 의 reference pattern:

1. `watch(isEffectiveHost)` writeCurrentLot guard — 기존 정합 시 skip
2. `lastTriggeredLotIdx` + 5s 재시도 (영구 차단 X)
3. `visibilitychange` 재동기화 → `_resyncSeq` 추적
4. `Math.ceil` + clamp (clock skew)
5. autoPickWorker abort 시 `console.warn` (silent X)

## 엔진 (useAuctionMultiState — C14b/c/d)

### 입찰 (placeBid — runTransaction)

```js
async function placeBid(teamIdx, amount) {
  const expectedIdx = currentIdx.value;
  const antiSnipeMs = auctionRule.antiSnipeExtendSec * 1000;

  return await runTransaction(currentLot, (cur) => {
    if (!cur) return;
    if (cur.idx !== expectedIdx) return;        // 다른 lot 진입 (race)
    if (cur.deadline < Date.now()) return;       // 타이머 종료
    if (cur.currentBid?.amount >= amount) return;// 이미 더 높은 입찰
    cur.currentBid = { teamIdx, amount, at: Date.now() };
    // antiSnipe 연장 — bid + 연장 atomic
    if (cur.deadline - now < antiSnipeMs) {
      cur.deadline = now + antiSnipeMs;
      cur.extendedCount = (cur.extendedCount ?? 0) + 1;
    }
    return cur;
  });
}
```

> [!info] race + 연장 atomic
> winner 한 명만 commit → 그 입찰이 연장 trigger. 늦은 사람 reject → 빈 연장 X.

### Finalize (effective host only)

```js
async function finalizeLot() {
  if (!isEffectiveHost.value) return { ok: false, err: "not-host" };
  if (deadline > Date.now()) return { ok: false, err: "not-due" };

  if (currentBid) {
    // sold → history append
    updates[`history/${idx}`] = { ..., reason: "sold" };
  } else {
    const count = relistQueueRef.value.get(subjectId) ?? 0;
    if (count < MAX_RELIST (2)) {
      // 재경매 → count++ + history relist-N
      updates[`relistQueue/${subjectId}`] = count + 1;
      updates[`history/${idx}`] = { ..., reason: "relist-N" };
    } else {
      // max relist → random fallback (자낳대 정합)
      pool = engineEligibleTeamIdxsForLot(...) || engineFallbackTeamIdxsForLot(...);
      updates[`history/${idx}`] = { ..., teamIdx: pick, reason: "random-after-max-relist" };
    }
  }
  await update(pathRoom, updates);
}
```

## 입찰 버튼 (C14c)

`+5 / +50 / +100 / 수동입찰` — 현재가 기준 증분. user 박힘 (2026-05-13).

- 본인이 최고가 = 4 버튼 disabled + "내가 최고가야" 안내
- 잔여 부족 = 부족한 버튼만 disabled
- 모든 버튼 disabled 시 = `allBidsDisabled`

## Timer + antiSnipe (C14c)

매물 카드 하단:
- ⏱ N초 + progress bar
- 마지막 5초 = `timer--snipe` (오렌지 pulse + "막판!" 배지)
- `Math.ceil` + clamp (5 trap pattern 정합)

antiSnipe 연장 로직:
- placeBid mutator 안에서 `remain < antiSnipeMs` 시 deadline 연장
- bid + 연장 atomic (race + 늦은 사람 reject → 빈 연장 X)

## AI bid (unclaimed)

> 4 자리 중 시청자 안 박힌 자리 = AI 가 대리 입찰. '혼자도 가능' 정합.

- `useAiPick.decideBid({ team, player, currentBid, ... })` 가 결정
- effective host 만 trigger
- jittered:
  - lot 변경 시: 800~1800ms
  - bid 갱신 시: 500~1200ms
- 자기 자신이 최고가면 skip

## Coach Selection (C14d)

> `coachAssignment.mode='remaining-points'` 시 auction 끝 후 자동 진입.

- 잔여 desc 순서 (tie-break: auction-seed)
- 1 팀씩 감독 후보 4 명 중 1 명 선택
- `selectCoach` = runTransaction race-safe (3 단계 가드: order/assigned/coachId)
- AI auto-select = rating desc 1번 픽 (남은 감독 중)
- toast = race reject 시 "이미 다른 선택 — 다시 시도"

## 헷갈리는 점

> [!warning] 자유 입찰 = turn-based 아님
> 4 시청자 동시 입찰. timer 만료 시 winner = 최고가. user verbatim (`feedback_auction_multi_free_bid_2026-05-12.md`).

> [!warning] race-safe = runTransaction
> placeBid mutator 안 3 단계 가드 (idx / deadline / amount). 동시 입찰 시 first commit win.

> [!warning] antiSnipe 는 mutator 안에서 atomic
> bid + 연장 한 트랜잭션. 별도 watch 박지 X (race 위험).

> [!warning] AI bid = effective host 만 trigger
> 모든 client trigger 시 중복 입찰. effective host 단일점.

> [!warning] coach-selection = remaining-points 만
> 다른 mode (none / auction-lot / lottery) 는 별 phase X.

> [!warning] RTDB rules deploy 안 됨
> 박힌 코드 + console permission_denied = rules 미배포. user 가 직접 박음.
