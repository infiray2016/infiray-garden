# v10 톤 (Card Clean)

> pickzzk 의 확정 디자인 톤. **라이트 배경 + 시그널 오렌지 + 하드 보더 + 박스 그림자**. 운영자 SaaS 가 아닌 **시청자 친화 인디 트래커** 라는 정체성에 맞춰 박힌 톤.

## 색 (CSS variables)

| 토큰 | 값 | 용도 |
|---|---|---|
| `--color-bg` | `#FAFAF6` | 라이트 배경 (basis) |
| `--color-ink` | `#161614` | 본문 텍스트 / 보더 |
| `--color-orange` | `#FF5B22` | 시그널 강조 (CTA / now / focus) |
| `--color-green` | `#2A8C58` | 성공 / 보조 |
| `--color-blue` | `#4865B8` | 정보 / 차분 |
| `--color-gold` | `#B98D29` | 강조 보조 (배지 등) |
| `--color-live-red` | `#FF2D2D` | LIVE 라벨 (현재 폐기 — LIVE 카드 X) |

## 폰트

- 한글: **Pretendard**
- 영문: **JetBrains Mono**
- 시청자 친화 카피 (terminal 문법 ↓)

## 박는 요소

- **하드 보더** (1.5 ~ 2px solid)
- **박스 그림자** (3-5 px offset, 보더 색 그대로 — orange / ink)
- **rounded 거의 없음** (6px max, 대부분 0)
- **layered** (overlap / depth)

## 폐기된 톤

- ❌ broadcast retro 톤 (어두운 / 네온 / CRT 효과)
- ❌ LIVE RED 방향 (실시간 매치 추적 X — 스크린샷 OCR 기반)
- ❌ 어두운 hero / 흑백 카드 → user 가 "라이트 v10 으로 박자" 박음 2026-04-30

## 위반 사례 (자주 박힘)

> [!warning] 검은 푸터 / 검은 배경 카드
> v10 위반. 라이트 + 보더 + 그림자 패턴 박아야.

> [!warning] UNDEFINED / "?" placeholder 직접 노출
> R5 룰 위반. skeleton / 안내 카피로 대체.

> [!warning] 의미 없는 데이터 노출
> "kind=inhouse" raw enum 라벨 / "R1 인기 픽 UNDEFINED 64%" 등.

> [!warning] 새 톤 임의로 박지 마
> v10 톤 = lock. 다른 톤 후보 (broadcast / dark luxury 등) 박지 마. R7 룰.

## 컴포넌트 패턴

### 카드 (HomeCard)
```css
border: 2.5px solid var(--color-ink);
background: var(--color-bg);
box-shadow: 5px 5px 0 var(--color-ink);
```

### CTA 버튼 (primary)
```css
background: var(--color-orange);
color: var(--color-ink);
border: 1.5px solid var(--color-ink);
box-shadow: 3px 3px 0 var(--color-ink);
font-weight: 800;
letter-spacing: 0.08em;
transition: transform 80ms;
```

```css
:hover { transform: translate(-1px, -1px); }
```

### 배지 (badge)
```css
background: var(--color-orange);
color: var(--color-ink);
padding: 2px 6px;
font-family: var(--font-mono);
font-weight: 800;
letter-spacing: 0.08em;
text-transform: uppercase;
```

## 헷갈리는 점

> [!warning] 시그널 오렌지 vs LIVE RED
> 시그널 = `#FF5B22` (강조) / LIVE = `#FF2D2D` (실시간 — 폐기됨). 라이브 카드 안 만들기로 박힘 (스크린샷 OCR 기반).

> [!warning] 카드 vs 배지
> 카드 = 큰 영역 (border 2.5px / shadow 5px) / 배지 = 작은 라벨 (padding 2-6px).

> [!warning] 다크 모드 default X
> user 박힘 2026-04-30 — 라이트 톤 only. 추후 다크 모드 박을 수 있지만 default 아님.
