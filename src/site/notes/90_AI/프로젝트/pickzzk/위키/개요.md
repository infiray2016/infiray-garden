# pickzzk 개요

> **치지직 (NAVER) 스트리머 LoL · 오버워치 인디 대회 시청자 트래커.** 시청자가 시청 재미를 위해 직접 만든 도구. 운영자 SaaS 아님.

## 한 줄 정의

치지직 카테고리의 스트리머 자낳대 / 호종컵 같은 인디 대회를 **시청자 입장에서 더 재미있게 보기 위한** non-official 트래커.

## 정체성 (헷갈리지 말 것)

| 무엇 | 무엇이 아님 |
|---|---|
| 시청자 도구 | 운영자 SaaS X |
| viewer-built | 회사 / 운영 조직 product X |
| 비공식 | 공식 API 사용 X (치지직 / Riot 정식 권한 X) |
| 트래커 | 라이브 매치 추적 X (스크린샷 OCR 기반) |

> [!warning] user = 시청자 — verbatim
> [[90_AI/claude/개념/메모리\|메모리]] 의 `user_role_viewer.md` 박힘:
> "user 는 시청자임 (운영자 아님 / 방송 안 함 / 시청 재미용)"

## 타겟 user

- 치지직 스트리머 대회 시청자 (LoL · 오버워치 카테고리)
- 자낳대 / 호종컵 같은 인디 대회 fan
- "지금 누가 누구랑 팀이지?" / "누가 누구한테 얼마에 박혔지?" 궁금한 사람
- 모의 시뮬 굴려보고 싶은 사람

## 게임 / 대회 범위

- **LoL** (League of Legends) — 자낳대 / 호종컵 시리즈
- **오버워치** (확장 의도) — 자낳대 시즌 시점에 박힘
- 스네이크 드래프트 / 포인트 경매 ([[90_AI/프로젝트/pickzzk/위키/셋업-룰\|셋업-룰]])
- 픽 주체 = 감독 또는 팀장 (4 조합)

## 데이터 수단

> 공식 권한 (치지직 / Riot API) 없이 데이터 만듦.

- **스크린샷 OCR** — 시청자가 결과창 / 전적 캡처 → 챔프 / KDA / 결과 추출
- **시청자 제보** — 운영자 + 시청자 둘 다 제보 가능
- **자체 streamersDB** — 마스터 컬렉션 (시즌 거듭하며 누적, LoL+OW 공유)
- **치지직 비공식 API** — 채널 정보 fetch (정책 변경 모니터링 필요)

## 운영 cadence

> 95%+ 시간 CLOSED. 활성 = 대회 시작 1주 전 ~ 종료.

- **휴면 = default** (3-4 개월 cadence)
- 활성 시기 = 대회 직전 부터 박힘
- cron / 자동 폴링 = CLOSED 기간엔 끔 (비용 0 지향)
- 활성 시 = pre-open → mock → scrim → final → archived

## 화면 우선순위 (CLAUDE.md 기준)

1. **활성 홈** — 시청자 진입 (현재 단계 + 카드 매핑)
2. **운영자 셋업** — 4 룰 × 팀수 한 번 설정, 출전 명단 cherry-pick
3. **스트리머 DB 관리** — 마스터 컬렉션 (채널 / 롤 / OW ID 통합)
4. **CLOSED 안내** — 정적 1장 (JS 없이 단순)
5. v1.x — 운영자 sub-admin 초대 + 기능별 role

자세히는 [[90_AI/프로젝트/pickzzk/위키/화면\|화면]].
