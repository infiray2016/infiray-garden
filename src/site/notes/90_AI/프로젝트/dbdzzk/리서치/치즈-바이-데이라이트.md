# 치즈 바이 데이라이트 (치바데)

> https://cheesebydaylight.vercel.app · v1.3.14 · **DBD 커스텀 게임 진행 보조 전용.** 전적·통계 기능 없음.

푸터 한 줄이 정체를 다 말한다 — "치바데는 데드 바이 데이라이트 커스텀 게임 진행 보조 프로그램입니다".
방송 중 스트리머가 켜 놓고 쓰는 **점수판**이지 기록 서비스가 아니다.

## 화면

홈에 버튼 두 개뿐이다. `4 vs 4 모드` → `/4v4`, `5인 내전 모드`.

4v4 화면은 좌 A팀 / 우 B팀 대칭 구조다.

- 팀당 4슬롯. 슬롯마다 **이름 입력 + 살인마 초상화 칸 + 해골 5개(0K~4K) 킬 버튼**
- 가운데 거대한 `0 VS 0` 스코어
- 슬롯 옆 아이콘 3종: 랜덤 / 인원 추가 / 인원 제거, 좌측 핸들로 드래그 재정렬

하단 컨트롤: `경매 순서 결정` · `선공 결정` · `살인마 목록 열기` · `초기화 메뉴` · `설명서` · `UI 끄기` · `점수판 연동 설정` · `5인 내전 모드로 전환`.

홈 배너에 최근 변경이 붙는다 — "에이스 결정전 기능이 개선되었습니다", "맞밸런스 추첨 기능이 추가되었습니다", 그리고 **피어리스(FEARLESS) 모드** 별도 홍보.

## 실시간 점수판 연동

> 세 사이트를 나란히 보려면 → [[90_AI/프로젝트/dbdzzk/파이프라인.excalidraw\|데이터 파이프라인 도면]]

진행자 브라우저에서 점수 입력 → (연동을 켤 때만) 익명 인증 + App Check → **RTDB `scoreboardRooms/{48~128자리 hex}`** → 상대·관전자가 WebSocket으로 **읽기 전용** 구독. 초대는 `#room=` URL 프래그먼트라 서버 로그에 안 남고, 방송이 끝나면 세션도 끝난다.

연동을 켜는 순간에야 익명 계정이 생기고(`identitytoolkit accounts:signUp`), App Check가 reCAPTCHA Enterprise 토큰을 교환한다. 즉 **평소엔 완전 로컬**, 공유할 때만 서버를 쓴다.

## 스택 (네트워크·번들에서 확인)

| 항목 | 확인된 내용 |
|---|---|
| 프레임워크 | Next.js App Router (Turbopack 청크명), 다크 전용 `class="dark"` |
| 호스팅 | Vercel + Vercel Analytics(`/_vercel/insights`) + 일부 이미지 Vercel Blob |
| 실시간 | Firebase Realtime Database (`cheesebydaylight-default-rtdb.asia-southeast1`) |
| 인증 | Firebase 익명 인증 + App Check(reCAPTCHA Enterprise) |
| 살인마 초상화 | **자체 호스팅** `/portraits/big/*.webp` 46종 (slasher, lich, wraith, ghoul, first …) |
| 폰트 | Godo (jsDelivr korean-webfonts) + S-CoreDream 자체 호스팅 |
| SEO | OG·keywords·google-site-verification까지 채움 ("치바데" 검색 대응) |

앵커 링크가 **0개**다. 전부 버튼과 클라이언트 라우팅이라 크롤러엔 홈 한 장으로 보인다. 홈 푸터에 GitHub 로고가 노출된다.

## dbdzzk 관점

[[90_AI/프로젝트/dbdzzk/README\|dbdzzk]]와 **거의 같은 자리**다. 진행 도구, 4v4 + 5인, 살인마 선택, 실시간 공유.

다른 점:
- 치바데는 방 개념 없이 "연동 시작" 시점에 주소를 뽑는다. dbdzzk는 방 코드가 먼저 있다.
- 치바데엔 OBS 투명 오버레이가 없다. dbdzzk엔 있다.
- 치바데는 살인마 초상화를 직접 호스팅한다. dbdzzk는 위키 CDN 외부 참조 → 링크가 깨지면 대체 표시.
- 양쪽 다 기록을 남기지 않는다. 다만 dbdzzk는 Firestore에 방이 남고, 치바데는 RTDB 세션이 전부다.
