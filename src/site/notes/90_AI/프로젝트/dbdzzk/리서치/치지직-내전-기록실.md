# 치지직 내전 기록실 (dbd.jetack.com)

> https://dbd.jetack.com · **진행 도구와 기록·레이팅을 한 서비스에 묶은 유일한 사이트.** 셋 중 가장 완성도가 높다.

멀티 게임 허브다. 홈에서 게임을 고른다.

- **데드 바이 데이라이트** `/dbd` — "62명 기록 중"
- **스타크래프트** `/sc` — 종족별 레이팅, "58세트 기록됨"

## 메뉴 (DBD 기준)

`홈` · `티어표` · `랭킹` · `4v4 통계` · `커스텀 통계` · `킬러 통계` · `경기 기록` · `내전 도구` · `게시판`

### 티어표 `/dbd/tiers`
"원탁 티어표". **기준 시각이 박힌 버전 스냅샷**을 드롭다운으로 고른다 (2026-08-07 22:00 최신 / 2026-08-05 06:00). 총점 ↔ 포지션별 토글. 12~1점 밴드에 선수를 얹는 형태.

### 랭킹 `/dbd/ranking`
"4v4 경기만 반영한 킬러·생존자 레이팅의 **합계**입니다. 한 포지션만 플레이한 선수는 그 포지션 점수를 그대로 씁니다."
`4v4` ↔ `5인·친선 포함` 토글, 순위표 ↔ 레이팅 그래프 토글, 순위 변동 화살표(▲▼).

### 4v4 통계 `/dbd/stats`
평균 킬 2.2, 총 614경기, 킬 분포 4K 205(33%) / 3K 65 / 2K 97 / 1K 152 / 0K 95.
**연장승부는 무승부, 승률 계산 시 0.5승.** 선수별로 라운드·승무패·승률·킬러 평균 킬·생존자 평균 팀탈출.

### 커스텀 통계 `/dbd/custom`
선수를 여럿 고르면 **그 선수들이 함께 뛴 경기만** 집계한다. 프리셋 제공(원탁 티어표 / 비행 따청년 / 백건실).

### 킬러 통계 `/dbd/killers`
픽률·밴율·평균 킬·킬 분포·최다 사용자. 분모를 명시한다 — "픽률은 킬러가 기록된 90개 라운드, 밴율은 밴이 기록된 14개 라운드 기준".

### 선수 페이지 `/dbd/players/{id}`
종합/킬러/생존자 레이팅, 킬 수 분포, 팀탈출 분포, 날짜별 레이팅 추이 그래프.

## 레이팅 모델

`/api/leaderboard` 응답이 그대로 설계도다.

```
player, total, totalRadius, totalDelta, games
killer   { rating, radius, delta, games, wins, draws, losses, killDist[5], winRate }
survivor { rating, radius, delta, games, wins, draws, losses, killDist[5], winRate }
modes    { "4v4": {...}, "5p": {...} }
ladders  { "4v4": { killer, survivor }, ... }
```

- **킬러와 생존자가 별도 레이팅**, 종합은 합계
- `radius` = 불확실성 반경. Glicko의 RD와 같은 역할이지만 **번들·API 어디에도 `glicko` 문자열은 없다** — 자체 구현으로 보인다
- **포맷별 라더 분리** (`4v4` / `5p` / all) — 포맷을 섞지 않는다
- `killDist`는 0K~4K 5칸 배열

## 신뢰 경계

홈에 대놓고 써 있다.

> 스트리머가 직접 입력하면 내전 종료 후 통계에 **바로 반영**됩니다. 시청자가 입력한 기록은 해당 스트리머 혹은 관리자의 **승인 이후** 통계에 합산됩니다.

공지에 "기록 오염 사용자 임시조치 안내"(2026-08-11), "레이팅 알고리즘 일부 수정"(08-14), "점수 미세조정 안내"(08-24)가 있다. **공개 통계를 열면 반드시 겪는 문제를 이미 겪고 운영으로 대응 중**이라는 뜻이다.

## OBS 오버레이 `/overlay`

치지직 채널/방송 주소를 붙여넣으면 브라우저 소스용 URL이 나온다.

- **한 번만 등록하면 끝** — 내전이 시작되면 자동으로 뜨고 끝나면 사라진다
- 권장 900 × 200, 남는 영역은 투명
- "크기를 바꾸려면 소스를 늘리지 말고 크기 설정을 바꾸세요. 소스를 늘리면 글자가 뭉개집니다" — OBS 운영 경험이 문서에 박혀 있다

**dbdzzk는 방 단위 URL, 여기는 채널 단위 URL.** 운영 편의는 채널 단위가 압도적이다.

## 게시판 `/board`

공지 + 사용자 글 + 댓글 수. 로그인은 치지직 OAuth(`/auth/chzzk/login?return_to=`).
글 목록에 "5인 내전 입력 중인데 드래그 순서 조정이 안 됩니다", "살인마 통계표도 있었으면", "4대4 내전 도구 개선점", 특정 경기 수정 요청 등 **실사용 피드백이 쌓여 있다**.
