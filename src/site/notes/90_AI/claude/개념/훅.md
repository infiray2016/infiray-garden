# 훅 (Hook)

> 특정 이벤트 발생 시 **자동 실행되는 shell 명령**. 세션 시작 / 도구 호출 후 / 세션 종료 등에서 사용. `.claude/settings.json` 에 정의.

## 한 줄 정의

**Claude 의 흐름 안에서 자동으로 끼어드는 스크립트.** 컨텍스트 박기, lint 강제, 검증 안내, 빌드 verify 등 [[90_AI/claude/개념/하네스\|하네스]] 룰을 코드 레벨로 강제.

## 종류 (이벤트별)

| 이벤트 | 언제 발동 | 예 |
|---|---|---|
| `SessionStart` | 세션 시작 시 | 브랜치 / git status / BOOTSTRAP 추가 컨텍스트 |
| `SessionStart:compact` | compact 후 세션 재시작 | 세션 요약 / 메모리 박기 |
| `UserPromptSubmit` | 사용자 메시지 전송 시 | 룰 환기 (R1 verify 알림 등) |
| `PreToolUse` | 도구 호출 직전 | 위험 도구 차단 / 파일 크기 가드 |
| `PostToolUse` | 도구 호출 후 | lint / 타입체크 자동 |
| `Stop` | 세션 종료 시 | 최종 build verify |

## 정의 위치

`.claude/settings.json` (또는 `~/.claude/settings.json` 글로벌):

```json
{
  "hooks": {
    "PostToolUse": [
      {
        "matcher": "Write|Edit",
        "command": "bun run lint-changed",
        "description": "변경 파일 lint"
      }
    ],
    "Stop": [
      {
        "command": "bun run build",
        "description": "세션 종료 시 build verify"
      }
    ]
  }
}
```

## matcher

도구 / 패턴 매치:
- `"Write|Edit"` — Write 또는 Edit 도구 호출 시
- `"Bash"` — bash 호출 시
- `"*"` — 전체

## 입력 / 출력

훅은 stdin 으로 도구 정보 (JSON) 받고, stdout 으로 안내 출력. stderr / exit code 2 로 차단 가능.

```bash
# stdin: { "tool": "Write", "tool_input": { "content": "...", "file_path": "..." } }
# stdout: 사용자에게 보이는 안내 (사용자 메시지처럼 박힘)
# exit 2: 도구 호출 차단 + stderr 메시지 표시
```

## 자주 쓰는 패턴 (pickzzk)

### 1. SessionStart — 핵심 룰 자동 환기

```json
"SessionStart": [
  { "command": "cat .claude/BOOTSTRAP.md", "description": "BOOTSTRAP 룰 컨텍스트" }
]
```

### 2. PostToolUse — 변경 후 검증 안내

```json
"PostToolUse": [
  {
    "matcher": "Write|Edit",
    "command": "echo '변경 후 bun run verify 필수'"
  }
]
```

### 3. PreToolUse — 위험 명령 차단

```json
"PreToolUse": [
  {
    "matcher": "Bash",
    "command": "node hooks/guard-dangerous.js"
  }
]
```

### 4. UserPromptSubmit — 작업 영역 룰 환기

pickzzk 가 자주 쓰는 패턴 — 사용자 메시지 안에 키워드 매치 시 관련 스킬 / 룰 환기:

```
하네스: CLAUDE.md + .claude/BOOTSTRAP.md + .claude/HARNESS.md ...
```

이게 사용자 prompt 에 자동으로 따라 박힘 → Claude 가 룰 환기.

## 훅 vs 스킬

| 구분 | 훅 | 스킬 |
|---|---|---|
| 본질 | shell 명령 자동 실행 | markdown 가이드 컨텍스트 박음 |
| 발동 | 이벤트 (도구 / 세션 / prompt) | 키워드 매치 / 슬래시 |
| 영향 | Claude 의 도구 결과 + 사용자 메시지 안에 박힘 | Claude 의 system 컨텍스트에 박힘 |
| 차단 가능? | yes (exit 2) | no (정보 박을 뿐) |

## 헷갈리는 점

> [!warning] 훅은 shell 에서 실행
> Claude 가 추론으로 안 함. `command` 가 실제 shell 에서 발동. 그래서 명령 형식이 정확해야.

> [!warning] PostToolUse 는 도구 결과 옆에 박힘
> 사용자에게 보이는 게 아니라 **Claude 의 다음 컨텍스트 안에** "PostToolUse hook additional context: ..." 형식으로 박힘.

> [!warning] 훅이 차단하면 도구 호출 안 됨
> exit 2 + stderr → 도구 자체가 실행 안 됨. PreToolUse 로 위험 도구 / 큰 파일 / 위험 명령 차단.

> [!warning] 글로벌 훅 vs 프로젝트 훅
> `~/.claude/settings.json` (글로벌) + `.claude/settings.json` (프로젝트) 동시 적용. 둘 다 실행. 충돌 / 중복 주의.

## 디버그 팁

- 훅 안 굴러가는 거 같으면 `command` 직접 shell 에 돌려봄
- stdout 에 박힌 것은 Claude 컨텍스트로 박힘 (사용자 안 봄)
- stderr 는 사용자에게 보임 (차단 시 메시지 노출)
- exit code 0 = 정상, 2 = 차단, 기타 = 오류 (무시)

## pickzzk 적용 (현재)

`.claude/hooks/` 와 `.claude/settings.json` 에 정의. 핵심:
- SessionStart:compact → 압축 후 컨텍스트 환기 (BOOTSTRAP + Vercel + Skills 안내)
- UserPromptSubmit → 작업 영역 룰 환기 (verify / browser matrix 등)
- PostToolUse → Vue / JS 편집 후 lint + regression + browser 안내
- ECC plugin → `ECC_HOOK_PROFILE=minimal` 로 standard+ 훅 비활성 (충돌 방지)
