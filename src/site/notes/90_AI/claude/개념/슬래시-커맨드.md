# 슬래시 커맨드 (Slash Command)

> 사용자가 `/<name>` 형식으로 명시 호출하는 트리거. 두 종류: **built-in** (Claude Code 시스템 명령) + **스킬 호출** (`.claude/skills/<name>/` 의 SKILL.md invoke).

## 한 줄 정의

**"이거 해" 라고 명시적으로 부르는 단축 명령.** `/help`, `/clear` 같은 built-in 도 있고, 스킬 / 플러그인 명령도 있음.

## 호출 방식

```
사용자 입력: /<name> [arguments]
```

예:
- `/help` — 도움말
- `/clear` — 컨텍스트 리셋
- `/checkpoint` — 안전망 체크포인트
- `/feature-mock-simulator` — 스킬 명시 invoke
- `/ultrareview` — 멀티 에이전트 클라우드 리뷰 (사용자 트리거, 빌링)
- `/loop` — 자동 반복 모드

## 종류

### 1. Built-in (Claude Code 시스템)

| 명령 | 역할 |
|---|---|
| `/help` | 도움말 표시 |
| `/clear` | 대화 컨텍스트 리셋 |
| `/exit` | 세션 종료 |
| `/fast` | Fast 모드 토글 (Opus 4.6) |
| `/checkpoint` | 안전망 체크포인트 |
| `/loop` | 자동 반복 모드 |
| `/ultrareview` | 멀티 에이전트 PR 리뷰 (별도 사용 시) |

> [!info] Built-in 은 Claude 가 직접 못 호출
> 사용자가 직접 입력해야 함. Claude 가 명령 흉내내도 안 동작 (e.g. text 로 "/help" 박아도 실행 X).

### 2. 스킬 호출 (`/<skill-name>`)

스킬 디렉토리 (`.claude/skills/<name>/` 또는 `~/.claude/skills/<name>/`) 의 SKILL.md 를 명시 invoke.

자동 invoke (description 매치) 와 차이:
- 자동 = 키워드 매치되면 invoke
- 슬래시 = 사용자가 명시 호출 (description 무관)

### 3. 플러그인 명령

플러그인 (`gstack`, `everything-claude-code` 등) 이 추가한 명령. 형식 다양:
- 단순: `/qa`
- prefix: `/gstack-qa` (skill_prefix=true 시)

## 호출 vs 자동 invoke

| 시나리오 | 호출 방식 |
|---|---|
| "AS-IS 확인해줘" | description 매치 → 자동 |
| "/feature-mock-simulator" | 사용자 명시 |
| "이 스킬 무조건 invoke" | 슬래시 (확실) |
| "키워드 잘 모름" | 슬래시 또는 description 다듬기 |

## 인자 (arguments)

```
/<command> <arg1> <arg2>
```

스킬 호출 시 인자는 SKILL.md 내부에서 사용 (e.g. `/ultrareview 123` = PR #123 리뷰).

## 헷갈리는 점

> [!warning] 슬래시 ≠ 스킬
> 슬래시 = 호출 메커니즘. 스킬 = 호출 대상 (markdown 가이드). 모든 슬래시가 스킬은 아님 (built-in 도 있음).

> [!warning] Claude 가 슬래시 명령 흉내 안 됨
> Claude 가 "/help" 같은 text 박아도 실행 X. **사용자가 직접 입력**해야 함.

> [!warning] `/clear` 와 `/exit` 차이
> - `/clear` = 컨텍스트만 리셋, 세션 계속
> - `/exit` = 세션 자체 종료

> [!warning] 자동 invoke 안 되는 경우
> description 키워드 매치 안 되면 슬래시 명시 호출 필요. "이 스킬 박혔는데 왜 안 굴러가지?" = 매치 keyword 확인.

## 사용자 / Claude 역할 분리

| 역할 | 슬래시 호출 |
|---|---|
| 사용자 | `/<name>` 직접 입력 |
| Claude | 스킬 자동 invoke (Skill 도구) |
| Claude | 사용자에게 "/명령 추천" 가능 (e.g. "`/checkpoint` 박는 게 좋겠어") |

> [!info] 자주 추천하는 패턴 (pickzzk)
> - 큰 작업 진입 전: `/checkpoint` 추천
> - 도움 필요: `/help`
> - 다른 작업 전환: `/clear`

## 실용 팁

- **자주 쓰는 작업 = 스킬 + description** — description 잘 박으면 슬래시 안 박아도 됨
- **확실히 invoke = 슬래시** — description 매치 신뢰 못 할 때
- **인자 전달 = 슬래시** (자동 invoke 는 인자 부족)
- **사용자가 `! <command>`** = bash 명령 (e.g. `gcloud auth login`) — 슬래시와 별개
