# 옵시디언 플러그인 — 고르는 기준과 이 볼트의 선택

> 출처: [Obsidian 활용 가이드 — 부록 1. 추천 플러그인 카탈로그](https://wikidocs.net/371869) (2026-08-19)

## 고르는 원칙

> 플러그인은 **기능보다 운영 비용**으로 고르는 것이 낫다. 최근 업데이트 상태, 모바일 동작, 데이터 접근 범위를 먼저 보면 실패 확률이 줄어든다.
> 먼저 **코어 기능으로 시험**하고, **반복되는 문제가 확인될 때** 하나씩 추가한다.

주의로 못 박은 것:

- 같은 문제를 푸는 플러그인을 **한꺼번에 겹쳐 깔면 설정만 늘어난다**
- 외부 API 를 쓰는 AI 플러그인은 **데이터가 어디로 가는지** 먼저 확인
- 자동 수정·자동 이동·자동 커밋은 **테스트 볼트에서 먼저**
- Local Backup 은 데스크톱 전용이고, **같은 디스크 복사본만으로는 기기 고장에 대비할 수 없다**

## 카탈로그 (트랙별)

| 트랙 | 플러그인 | 용도 |
|---|---|---|
| 입문 | Templater · QuickAdd · Calendar | 반복 양식 · 캡처 단축 · 데일리 노트 |
| 실전 | Tasks · Kanban · Omnisearch | 마감/반복 태스크 · 상태 보드 · 본문 검색 |
| 데이터 | **Dataview** · Metadata Menu · Tracker | 속성 조회·집계 · 속성 입력 보조 · 수치 시각화 |
| 시각화 | Excalidraw · **Advanced Canvas** | 손그림 다이어그램 · Canvas 확장 |
| AI | Copilot · Smart Connections · Text Generator | 에이전트 · 의미 검색 · 텍스트 생성 |
| 안정성 | Obsidian Git · **Local Backup** · Remotely Save | 버전 관리 · 로컬 복사본 · 외부 스토리지 |

## 이 볼트에 깐 것 — 문제 기준으로만

| 플러그인 | 왜 |
|---|---|
| `advanced-canvas` **7.0.0** | 기본 캔버스는 엣지가 `arrow`/`none` 뿐이라 점선·번호 원·직각 라우팅이 없다. 실제로 막혀서 깔았다 → [[90_AI/claude/개념/클로디언\|개념/클로디언]] · `vault-diagram` 스킬 |
| `dataview` **0.5.x** | 태그 83개 중 **52개가 1회용**, 태그 없는 노트 39개, 고아 노트 34개. 상시 갱신되는 볼트 위생 현황판이 필요하다 |
| `local-backup` **0.2.5** | **LiveSync 원격(시놀로지 CouchDB)이 502 로 죽어 있어** 실질 복구 지점이 iCloud 하나뿐이다. 게다가 [[90_AI/claude/개념/클로디언\|개념/클로디언]]이 볼트에 쓰기 권한을 갖는다 — 실수 복구 지점이 있어야 한다 |
| `realclaudian` **2.2.5** | Claude Code 를 옵시디언 안에서 |
| `obsidian-livesync` | 기존 |

## 일부러 안 깐 것

원칙이 "반복되는 문제가 확인될 때"라서, 아직 문제가 없는 건 넘겼다.

- **Templater · QuickAdd · Calendar** — 이 볼트는 데일리 노트를 안 쓴다
- **Tasks · Kanban** — 할일 관리를 볼트에서 하지 않는다 (`할일/` 은 메모 수준)
- **Omnisearch** — 노트 107개면 코어 검색으로 충분하다
- **Excalidraw** — 도표는 `vault-diagram` 스킬이 SVG 로 만든다. 손그림이 필요해지면 그때
- **Copilot · Smart Connections · Text Generator** — 클로디언과 같은 문제를 푼다. **겹쳐 깔지 말라**는 원칙에 정면으로 걸린다
- **Obsidian Git** — 볼트가 iCloud 안이라 git 과 충돌 위험. Local Backup 으로 먼저 시험

## 노트 쓸 때 참고

- 속성(`tags` · `updated` · `status`)을 일관되게 박아야 Dataview 가 쓸모 있어진다
- 폴더·태그·속성은 **역할을 나눈다** — 폴더는 위치, 태그는 횡단 분류, 속성은 조회용 값
- MOC(허브 노트)로 흩어진 주제를 잇는다. 이 볼트의 고아 노트 34개가 그 대상이다
