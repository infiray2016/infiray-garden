# 에이전트 (Agent)

> Claude (Anthropic 의 LLM) 자체가 **에이전트**. system 룰 + tool 호출 + 컨텍스트 관리로 자율적으로 작업하는 주체. "Claude Code" 는 이 에이전트가 CLI 환경에서 도구를 쓰며 일하게 만든 wrapper.

## 한 줄 정의

**LLM + 도구 호출 능력 + 컨텍스트 (메시지 히스토리) = 에이전트.** Claude Code 의 메인 세션이 곧 1 차 에이전트.

## 구성 요소

```
┌─────────────────────────────────────┐
│ System prompt                       │  ← Anthropic 이 박은 + CLAUDE.md 등
├─────────────────────────────────────┤
│ User messages (대화)                │  ← 사용자 입력
├─────────────────────────────────────┤
│ Tool calls (Bash / Read / Edit / …) │  ← 에이전트가 부르는 도구
├─────────────────────────────────────┤
│ Tool results                        │  ← 도구 응답
└─────────────────────────────────────┘
       ↓
   다음 액션 결정 (LLM 추론)
```

## 메인 에이전트의 특징

- **컨텍스트 = 대화 전체**. 시작부터 끝까지 모든 메시지 / 도구 결과 누적
- **자동 compact** — 컨텍스트 한계 가까워지면 시스템이 압축 (이전 대화 요약)
- **권한** — `.claude/settings.json` 으로 도구별 자동 / 확인 / 차단 분리
- **하네스 자동 적용** — [[90_AI/claude/개념/하네스\|하네스]] 의 룰 / [[90_AI/claude/개념/스킬\|스킬]] / [[90_AI/claude/개념/훅\|훅]] 이 컨텍스트에 박힘

## 에이전트가 박힐 때 흐름

```
1. 세션 시작
   ↓
2. CLAUDE.md + .claude/BOOTSTRAP.md 자동 로드  (= 하네스 컨텍스트)
   ↓
3. SessionStart 훅 실행 (브랜치 정보 / git status / 메모리 인덱스)
   ↓
4. 사용자 입력 대기
   ↓
5. 입력 받음 → keyword 매치 → 스킬 자동 invoke?
   ↓
6. 추론 → 도구 호출 (Bash / Read / Edit / …)
   ↓
7. 도구 결과 → 다음 액션 결정
   ↓
8. (반복) 또는 사용자 응답 / 질문
```

## 한계

- **컨텍스트 한계** — 대화 길어지면 compact. 압축 후 디테일 손실 가능
- **세션 격리** — 다른 세션 / 다른 디렉토리는 컨텍스트 X. 인계는 [[90_AI/claude/개념/메모리\|메모리]] 통해
- **추측 위험** — 모르면 그럴듯한 답 박음 ([[90_AI/claude/개념/하네스\|하네스]] R8 verbatim 룰로 방어)
- **검증 누락** — 결과 자체가 LLM 출력이라 자가 검증 어려움 → [[90_AI/claude/개념/훅\|훅]] 으로 자동 lint / build

## 메인 에이전트 vs [[90_AI/claude/개념/서브에이전트\|서브에이전트]]

| 구분 | 메인 에이전트 | 서브에이전트 |
|---|---|---|
| 호출 | 세션 시작 시 자동 | Task tool 로 명시 호출 |
| 컨텍스트 | 대화 전체 | 격리됨 (호출 prompt + 결과만) |
| 결과 | 사용자에게 직접 | text 결과 → 메인 에이전트로 |
| 비용 | 누적 | 호출 단위 |
| 용도 | 사용자 대화 / 메인 작업 | 격리된 탐색 / 병렬 / 컨텍스트 보호 |

## 헷갈리는 점

> [!warning] 에이전트 ≠ 하네스
> - **에이전트** = 실행 주체 (LLM)
> - [[90_AI/claude/개념/하네스\|하네스]] = 에이전트가 따르는 룰 체계 (markdown)

> [!warning] 메인 에이전트는 1 개만
> 1 세션 = 1 메인 에이전트. [[90_AI/claude/개념/서브에이전트\|서브에이전트]] 는 여러 개 동시 호출 가능하지만 메인은 1 개.

> [!warning] 컨텍스트는 영구가 아님
> Compact 가 일어나면 초반 대화 사라짐. 중요한 결정 / 룰은 [[90_AI/claude/개념/메모리\|메모리]] 에 박아야 다음 세션에 전달됨.

> [!warning] "Claude Code" = 에이전트 자체가 아니라 CLI wrapper
> Claude (LLM) + 도구 (Bash 등) + 권한 / 훅 시스템 = Claude Code. 에이전트는 Claude 부분만.

## 실용 팁

- **긴 탐색은 [[90_AI/claude/개념/서브에이전트\|서브에이전트]] 위임** — 메인 컨텍스트 보호
- **결정 박히면 [[90_AI/claude/개념/메모리\|메모리]] 박음** — 다음 세션 컨텍스트 인계
- **`/checkpoint`** — 큰 작업 진입 전 안전망 (터미널 종료 대비)
- **`/clear`** — 컨텍스트 리셋 (다른 작업으로 전환 시)
