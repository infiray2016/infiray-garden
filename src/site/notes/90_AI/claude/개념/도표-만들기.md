# 도표 만들기 — 뭘 쓰고 어떻게 만드나

> 이 볼트에서 그림을 만들 때의 기준과 도구. **도구나 규칙이 바뀌면 이 노트도 같이 고친다.**

## 뭘 쓸지 고르기

| 상황 | 도구 | 결과물 |
|---|---|---|
| **대부분의 개념도 · 흐름도 · 구조도** | **Excalidraw** | `*.excalidraw.md` |
| 노트에 박는 정적 도판 (색·여백을 픽셀 단위로 통제) | SVG 생성 | `_그림/*.svg` + `![[파일.svg]]` |
| **내가 직접 끌어다 배치할 판** | 캔버스 | `*.canvas` |
| 비교 · 수치 | 그냥 마크다운 표 | — |

Mermaid 는 쓰지 않는다. 모양이 나쁘고 통제가 안 된다.

**보통은 Excalidraw.** 화살표가 도형에 붙어서 박스를 옮기면 따라오고, 가까운 변을 알아서 고른다.
캔버스는 *내가 손으로 배치하고 싶을 때만* 쓴다 — 에이전트가 좌표를 찍는 용도로는 Excalidraw 가 낫다.

## 누가 만드나

### 스킬 `vault-diagram` — 생성

`.claude/skills/vault-diagram/`

| 스크립트 | 하는 일 |
|---|---|
| `exgen.py` | **Excalidraw 도면 생성.** 박스·화살표·비교축 + 문서용 도형(아래). `check()` 로 관통/겹침 자가검사 |
| `exrender.mjs` | **실제 Excalidraw 엔진으로 렌더 + 검사.** 압축 저장본도 자동으로 푼다 |
| `archsvg.py` | 정적 SVG 도판. 점선 영역 · 곡선 화살표 · 번호 원 · 범례 |
| `canvasgen.py` | 캔버스 생성. 텍스트에서 노드 높이를 자동 계산 |
| `canvasrender.mjs` | 캔버스를 옵시디언 규칙대로 그려서 눈으로 확인 |

### 스킬 `canvas-review` — 검토

`.claude/skills/canvas-review/scripts/review.py`

캔버스의 텍스트 넘침 · 노드/그룹 겹침 · 그룹 라벨 충돌 · 끊어진 엣지 · 임베드 줌 문제 등을 잡는다.

## 볼트 밖에서도 쓰기

스킬 원본은 볼트 안에 두고 `~/.claude/skills/` 에 **심링크**를 걸었다. 어느 프로젝트에서 클로드코드를 켜든 두 스킬이 잡힌다.

```
~/.claude/skills/vault-diagram -> <볼트>/.claude/skills/vault-diagram
~/.claude/skills/canvas-review -> <볼트>/.claude/skills/canvas-review
```

원본이 하나뿐이라 고치면 양쪽에 바로 반영된다. 복사본을 따로 맞출 일이 없다.

- **볼트 경로** — `OBSIDIAN_VAULT` 환경변수로 덮어쓴다. 안 주면 이 볼트가 기본값.
  스텐실 라이브러리를 찾는 데만 쓰므로, 볼트 밖에서는 스텐실 없이 도형만 그려진다(예외 안 남).
- **playwright** — `exrender.mjs` / `canvasrender.mjs` 가 쓴다. 프로젝트마다 깔지 않도록
  `~/.claude/lib/` 에 고정 설치하고 `~/node_modules/playwright` 심링크로 연결해뒀다.
- **인터넷** — Excalidraw 엔진과 `lz-string` 은 CDN 에서 받는다. 오프라인이면 렌더가 안 된다.

### 문서용 도형 (exgen)

SI 산출물처럼 밀도 높은 그림에 쓴다. 일반 `box`/`arrow` 로는 안 된다.

| 메서드 | 쓰는 곳 |
|---|---|
| `region(…)` | **중첩 컨테이너.** AWS Cloud > VPC > AZ > Subnet 처럼 감쌀 때 |
| `card(…, num, title, sub, chip, accent)` | 상단 컬러바 + 번호 배지 카드. 파이프라인 단계 |
| `tablebox(…, name, rows, bold=())` | ERD 테이블. 컬러 헤더 + 속성 행 |
| `badge(…, n)` | 번호 원 |
| `orth(id, pts, …)` | **직교 화살표.** 꺾인 점을 직접 준다. 대각선 금지 |
| `icon_node(…, icon, title, sub)` | **아이콘 노드.** 스텐실 + 제목 + 부제를 한 그룹으로 |
| `card(…, icon='KMS')` | 카드 오른쪽 위에 아이콘. 파이프라인 단계별로 다르게 |
| `band(…)` / `lifeline(…)` | 시퀀스 다이어그램의 구간 띠 · 생명선 |

- **컨테이너는 검사에서 빠진다.** `region`/`band` 는 자식을 품는 게 정상이라
  `customData.container` 표시를 달아 파이썬·렌더러 양쪽이 같이 제외한다.
- **`orth` 는 각진 모서리**를 쓴다. 둥글게 하면 긴 경로가 크게 휘어 지저분해진다.
- 검사는 화살표의 **꺾인 실제 경로**를 따라간다. 시작→끝 직선만 보면 헛다리를 짚는다.
- **같은 그룹 안은 검사에서 뺀다.** 스텐실 내부에 화살표가 들어 있는 아이콘(RDS 등)이 있어서,
  안 그러면 자기 프레임을 관통한다고 잡힌다.

## 기대는 플러그인

| 플러그인 | 왜 필요한가 |
|---|---|
| **Excalidraw** `2.26.4` | 도면을 그리고 편집한다. 없으면 `.excalidraw.md` 가 그냥 텍스트로 보인다 |
| **Advanced Canvas** `7.0.0` | 기본 캔버스는 엣지가 `arrow`/`none` 뿐이다. 점선 · 번호 원(`shape: circle`) · 직각 라우팅이 이 플러그인 덕에 된다 |

> [!warning] 노트를 PDF 로 뽑을 때
> Excalidraw 설정의 **"Render Excalidraw as Image in Obsidian PDF Export"** 가 꺼져 있으면
> 임베드한 도면이 **PDF 에서 통째로 빠진다**(노트 화면에서는 멀쩡히 보인다). 배포본 만들기 전에 켤 것.

## 만들고 나서 — 반드시 렌더해서 본다

기하 계산만으로는 못 잡는다. 실제로 그려봐야 보인다.

```bash
node <스킬>/scripts/exrender.mjs <파일>.excalidraw.md out.png   # Excalidraw (흰 배경·딱 맞게)
node <스킬>/scripts/exrender.mjs <파일>.excalidraw.md out.png --scale=3 --bg=transparent --pad=24
node <스킬>/scripts/canvasrender.mjs <파일>.canvas out.png      # 캔버스
python3 <canvas-review>/scripts/review.py <볼트> --all           # 캔버스 정적 검사
```

렌더러가 `검사: ✅ 관통 0 · 겹침 0` 을 찍어야 통과다.

## 워드 · PDF 문서로 뽑기

도면은 옵시디언 밖에서도 쓴다. 마크다운·볼트 없이 **워드 문서에 바로 넣을 수 있다.**

```
exgen.py ──> .excalidraw.md ──exrender──> PNG(흰 배경, 딱 맞게) ─┐
                                                                  ├─> docx-js ─> .docx ─soffice─> .pdf
si-design-docs 서식 (표지·러닝헤더·네이비 표·번호 절) ────────────┘
```

| 하는 일 | 도구 | 어디 |
|---|---|---|
| 문서 골격·표·목차 | `docx` 스킬 (docx-js v9.7.1) | `~/.claude/skills/docx` |
| 국내 SI 표준 서식 | `si-design-docs` 스킬 | `~/.claude/skills/si-design-docs` |
| 도면 | `vault-diagram` (Excalidraw) | 볼트 (심링크) |
| 검증 | `soffice` → `pdftoppm` → 눈으로 확인 | 시스템 |

- `docx` · `pptx` · `xlsx` · `pdf` · `si-design-docs` 는 **데스크탑 클로드 앱의 번들 스킬을 복사**한 것이다.
- **matplotlib 은 이 환경에 없다.** `si-design-docs` 원본은 다이어그램을 matplotlib 으로 그리게 돼 있었는데,
  Excalidraw 를 쓰도록 고쳐 놓았다. ERD·AWS 공식 아이콘이 필요하면 그때 matplotlib 을 깐다.
- 문서에 넣을 도면은 **제목을 넣지 않는다.** 문서가 `[그림 N]` 캡션을 따로 붙인다.
- A4 세로 본문폭은 **602px**. `--scale=3` 으로 뽑아야 인쇄에서 안 뭉개진다.
- pandoc 으로 마크다운을 변환하는 길도 되지만 **폰트가 들쭉날쭉하다.** docx-js 쪽을 쓴다.

## 그림 규칙 (형태와 무관)

몇 번 갈아엎고 남은 것들이다.

1. **노드 하나 = 이름 한 줄 + 설명 한 줄.** 그 이상은 그림이 아니라 슬라이드가 된다
2. **`·` 나열 금지.** 수치 · API 이름 · 파일명 같은 상세는 노트에 두고 그림에서 뺀다
3. **내용에 맞는 형태를 고른다** — 흐름이면 왼→오, 비교면 축 위 배치, 공통 결론이면 합류.
   전부 3열 박스로 만들면 내용이 뭐든 똑같아 보인다
4. **화살표가 교차하거나 박스를 뚫으면 배치가 틀린 것이다.** 선 모양을 바꾸지 말고 배치를 고친다.
   갈래가 여럿이면 **마지막(가장 아래) 노드에서** 결론으로 내려보낸다
5. **체커 숫자를 화면 품질보다 위에 두지 말 것.** 임베드 배율을 맞추려다 폭을 줄여서
   전체가 세로로 늘어진 적이 있다

| `basic-shapes` | 32 | 기본 도형 |
| `system-design` | 24 | 고수준 시스템 다이어그램 부품 |

### 생성기에서 꺼내 쓰기

`exgen.py` 가 이름으로 스텐실을 꺼내 배치한다. **이름이 붙은 건 `it-icons`(48) 과 `flow-chart-symbols`(15) 뿐**이고,
나머지는 구형 포맷이라 이름이 없어 편집기에서 직접 끌어다 쓴다.

```python
from exgen import Draw, library_index
library_index()                                    # 쓸 수 있는 이름 61개
d.stencil("srv-ic", "Server", x, y, size=48, color='#2f9e44')
```

- **`labels=False` 가 기본** — 스텐실에 딸린 영문 이름표("User", "Server")를 뺀다. 넣으면 도면에 영어가 섞인다
- 아이콘은 **화살표 경로를 피해** 놓는다. 선 위에 얹히면 지저분하다
- 자주 쓰는 것: `User` `Server` `Database` `Cloud` `Internet` `Device` `Firewall` `Network` `Bar chart` `Key` `Message`
- 흐름도 기호: `Start / End` `Process` `Decision` `Document` `Database` `Connector` `Delay`

> [!note] 필요하면 계속 추가한다
> [libraries.excalidraw.com](https://libraries.excalidraw.com/) 에서 받아 `Excalidraw/Libraries/` 에 넣으면 바로 잡힌다.
> 231개가 있으니 **필요가 생겼을 때** 하나씩 늘린다 — 미리 다 깔면 고르는 비용만 커진다.

- **2026-10-15** — 검사에 **글자 가로지름**을 추가했다. 화살표 선분이 글자 상자를 지나면 잡는다(`Draw.check()` 셋째 항목, `exrender.mjs` 는 브라우저에서 실제 글꼴로 폭을 잰다).
  도형만 보던 검사가 `관통 0 · 겹침 0` 인데도 타일 아래 글자를 화살표가 가로지른 그림을 통과시켰다. 번호 원 · `text(on_line=True)` · 도형에 붙은 글자는 빼고, 영역 탭 라벨은 탭 전체를 본다.
  같이 고친 것: `stencil()` 이 선의 범위를 `points` 로 잡는다(라이브러리의 낡은 폭 때문에 아이콘이 어긋났다) · `tablebox(foot, radius)` · 키 표식 글자 폭(옵시디언이 "P/K" 로 접던 것).
